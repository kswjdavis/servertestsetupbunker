# Story 2.9: End-to-End Integration Test

## Status
Ready for Dev

## Story
**As a** development team,
**I want** end-to-end integration test that verifies the complete system works together,
**so that** we're confident all components integrate correctly before proceeding to UI development.

## Acceptance Criteria

1. Backend server running with database and weather integration
2. ESP32 provisioned and authenticated successfully
3. ESP32 reports status every 60 seconds
4. Server receives status and updates database
5. Control logic engine makes shutdown decisions based on wind
6. ESP32 receives shutdown commands and controls relay
7. Dead-man timer resets when server responds
8. All API endpoints functional and tested via Postman/curl
9. System runs continuously for 1 hour without errors
10. Integration test documented with screenshots/logs

## Tasks / Subtasks

- [ ] Setup complete test environment
  - [ ] Backend running on localhost
  - [ ] PostgreSQL with test data
  - [ ] ESP32 flashed and connected

- [ ] Execute integration test sequence
  - [ ] Provision device via API
  - [ ] Flash auth token to ESP32
  - [ ] Monitor status reports for 1 hour
  - [ ] Manually adjust wind threshold to test decisions
  - [ ] Verify relay responds correctly

- [ ] Document results
  - [ ] Screenshot of database showing device_status updates
  - [ ] ESP32 serial logs showing status reports
  - [ ] Backend logs showing control decisions

## Dev Notes

Integration test checklist:
- ✅ Backend starts without errors
