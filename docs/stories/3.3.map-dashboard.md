# Story 3.3: Map Dashboard with Leaflet

## Status
Draft

## Story
**As a** web UI operator,
**I want** interactive map showing all bunker locations with status indicators,
**so that** I can see the geographic distribution and status of all bunkers (FR26, FR27).

## Acceptance Criteria

1. Leaflet map displayed as landing page after login
2. Map centered on average of all bunker locations
3. Markers placed at each bunker GPS coordinates
4. Marker color indicates bunker status: green (all fans ON), blue (energy saving), red (offline)
5. Click marker navigates to bunker detail page
6. Current wind data displayed on map (speed, direction arrow)
7. Map is responsive and works on tablet/desktop
8. Markers cluster if many bunkers in same area (optional)
9. Poll GET /api/v1/bunkers every 3 seconds for updates
10. Loading state shown while fetching bunkers

## Dev Notes

```typescript
import { MapContainer, TileLayer, Marker, Popup } from 'react-leaflet';
import 'leaflet/dist/leaflet.css';

const MapDashboard = () => {
  const [bunkers, setBunkers] = useState<Bunker[]>([]);

  useEffect(() => {
    const fetchBunkers = async () => {
      const data = await api.get('/bunkers');
      setBunkers(data);
    };

    fetchBunkers();
    const interval = setInterval(fetchBunkers, 3000);
    return () => clearInterval(interval);
  }, []);

  const center = calculateCenter(bunkers);

  return (
    <MapContainer center={center} zoom={10} className="h-screen">
      <TileLayer url="https://{s}.tile.openstreetmap.org/{z}/{x}/{y}.png" />
      {bunkers.map(bunker => (
        <Marker key={bunker.id} position={[bunker.latitude, bunker.longitude]}>
          <Popup>{bunker.name}</Popup>
        </Marker>
      ))}
    </MapContainer>
  );
};
```
