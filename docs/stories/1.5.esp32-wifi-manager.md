# Story 1.5: ESP32 WiFi Manager and NVS Storage

## Status
Draft

## Story
**As an** ESP32 firmware developer (Jeff),
**I want** WiFi connection management with credential storage in NVS flash,
**so that** the ESP32 can connect to WiFi reliably and store configuration persistently.

## Acceptance Criteria

1. ESP32 initializes WiFi subsystem on boot
2. WiFi credentials (SSID, password) stored in NVS flash (encrypted partition)
3. Device authentication token stored in NVS flash
4. ESP32 connects to WiFi using stored credentials automatically
5. WiFi reconnection strategy implemented: 30s intervals for 5 attempts, then 2min intervals (FR14)
6. WiFi connection events logged via ESP_LOG
7. NVS initialization handles first-boot (no credentials) gracefully
8. Basic provisioning mode (AP mode) allows credential entry for testing
9. MAC address retrieved and stored for device registration
10. Code follows ESP-IDF 5.x async patterns

## Dev Notes

### WiFi Initialization (ESP-IDF 5.x)

```c
#include "esp_wifi.h"
#include "esp_netif.h"
#include "nvs_flash.h"
#include "esp_log.h"

static const char *TAG = "wifi_manager";

void wifi_init(void) {
    // Initialize NVS
    esp_err_t ret = nvs_flash_init();
    if (ret == ESP_ERR_NVS_NO_FREE_PAGES || ret == ESP_ERR_NVS_NEW_VERSION_FOUND) {
        ESP_ERROR_CHECK(nvs_flash_erase());
        ret = nvs_flash_init();
    }
    ESP_ERROR_CHECK(ret);

    // Initialize TCP/IP adapter
    ESP_ERROR_CHECK(esp_netif_init());
    ESP_ERROR_CHECK(esp_event_loop_create_default());

    // Create default WiFi station
    esp_netif_create_default_wifi_sta();

    // Initialize WiFi
    wifi_init_config_t cfg = WIFI_INIT_CONFIG_DEFAULT();
    ESP_ERROR_CHECK(esp_wifi_init(&cfg));

    // Register event handlers
    ESP_ERROR_CHECK(esp_event_handler_register(WIFI_EVENT, ESP_EVENT_ANY_ID, &wifi_event_handler, NULL));
    ESP_ERROR_CHECK(esp_event_handler_register(IP_EVENT, IP_EVENT_STA_GOT_IP, &ip_event_handler, NULL));

    ESP_ERROR_CHECK(esp_wifi_set_mode(WIFI_MODE_STA));
}
```

### NVS Storage Functions

```c
#include "nvs.h"

esp_err_t nvs_save_wifi_credentials(const char *ssid, const char *password) {
    nvs_handle_t handle;
    esp_err_t err = nvs_open("bunker_config", NVS_READWRITE, &handle);
    if (err != ESP_OK) return err;

    err = nvs_set_str(handle, "wifi_ssid", ssid);
    if (err == ESP_OK) {
        err = nvs_set_str(handle, "wifi_pass", password);
    }

    nvs_commit(handle);
    nvs_close(handle);
    return err;
}

esp_err_t nvs_load_wifi_credentials(char *ssid, char *password) {
    nvs_handle_t handle;
    esp_err_t err = nvs_open("bunker_config", NVS_READONLY, &handle);
    if (err != ESP_OK) return err;

    size_t ssid_len = 32, pass_len = 64;
    err = nvs_get_str(handle, "wifi_ssid", ssid, &ssid_len);
    if (err == ESP_OK) {
        err = nvs_get_str(handle, "wifi_pass", password, &pass_len);
    }

    nvs_close(handle);
    return err;
}
```

### WiFi Reconnection Task (FR14)

```c
void wifi_reconnect_task(void *pvParameters) {
    int retry_count = 0;
    const int MAX_FAST_RETRIES = 5;
    const int FAST_RETRY_DELAY_MS = 30000;  // 30 seconds
    const int SLOW_RETRY_DELAY_MS = 120000; // 2 minutes

    while (1) {
        if (!wifi_is_connected()) {
            ESP_LOGI(TAG, "WiFi disconnected, attempting reconnection (attempt %d)", retry_count + 1);
            esp_wifi_connect();

            retry_count++;
            int delay_ms = (retry_count <= MAX_FAST_RETRIES) ? FAST_RETRY_DELAY_MS : SLOW_RETRY_DELAY_MS;
            vTaskDelay(pdMS_TO_TICKS(delay_ms));
        } else {
            retry_count = 0;  // Reset counter on successful connection
            vTaskDelay(pdMS_TO_TICKS(10000));  // Check every 10s when connected
        }
    }
}
```

### MAC Address Retrieval

```c
void get_mac_address(char *mac_str) {
    uint8_t mac[6];
    esp_read_mac(mac, ESP_MAC_WIFI_STA);
    snprintf(mac_str, 18, "%02X:%02X:%02X:%02X:%02X:%02X",
             mac[0], mac[1], mac[2], mac[3], mac[4], mac[5]);
    ESP_LOGI(TAG, "MAC Address: %s", mac_str);
}
```
