# Story 3.2: Login/Logout UI

## Status

## Story
**As a** web UI operator,
**I want** login page with username/password form,
**so that** I can authenticate and access the bunker control system.

## Acceptance Criteria

1. Login page with username and password fields
2. Form validation (required fields, minimum lengths)
3. Submit calls POST /api/v1/auth/login
4. Success: store token in localStorage, redirect to /dashboard
5. Error: display error message below form
6. Logout button in header calls POST /api/v1/auth/logout
7. Logout clears localStorage and redirects to /login
8. Loading state shown during login API call
9. Form accessible via keyboard (Enter to submit)
10. Responsive design works on tablet and desktop

## Dev Notes

```typescript
// pages/LoginPage.tsx
const LoginPage = () => {
  const { login } = useAuth();
  const [loading, setLoading] = useState(false);
  const [error, setError] = useState('');

  const handleSubmit = async (e: React.FormEvent) => {
    e.preventDefault();
    setLoading(true);
    try {
      await login(username, password);
      navigate('/dashboard');
    } catch (err) {
      setError('Invalid username or password');
    } finally {
      setLoading(false);
    }
  };

  return (
    <div className="min-h-screen flex items-center justify-center bg-gray-100">
      <form onSubmit={handleSubmit} className="bg-white p-8 rounded shadow-md w-96">
        <h1 className="text-2xl font-bold mb-6">Bunker Control Login</h1>
        {/* Form fields */}
      </form>
    </div>
  );
};
```
