# Story 4.5: Per-Bunker Configuration Overrides

## Status
Ready for Dev

## Story
**As a** system administrator,
**I want** to set custom wind thresholds and costs per bunker,
**so that** I can account for variations in bunker risk tolerance and local electricity rates (FR33).

## Acceptance Criteria

1. Configuration section on bunker detail page
2. Option to override global wind threshold with per-bunker value
3. Option to override electricity cost per bunker
4. "Use Global Settings" checkbox (sets overrides to null)
5. Save updates via PUT /api/v1/bunkers/:id
6. Show current global defaults for reference
7. Form validation (positive numbers)
8. Success message after save
9. Visual indicator when using custom vs global settings
10. Help text explaining overrides

This story implements per-bunker configuration overrides, allowing administrators to customize wind thresholds and electricity costs for individual bunkers while maintaining global defaults as fallbacks.

### API Endpoints

[Source: architecture.md#REST API Specification]

**GET /api/v1/config**
Response:
```typescript
{
  id: number;                                // Always 1 (singleton)
  default_wind_threshold_mph: number;        // Global default
  default_electricity_cost_kwh: number;      // Global default
  default_fan_power_watts: number;
  weather_station_id: string;
  weather_poll_interval_seconds: number;
  shutdown_broadcast_interval_seconds: number;
  device_offline_threshold_seconds: number;
}
```

**PUT /api/v1/bunkers/:id**
Request (partial update):
```typescript
{
  wind_threshold_mph?: number | null;      // null = use global
  electricity_cost_kwh?: number;           // Always required
}
```
Response: Updated Bunker object

### Component Implementation

[Source: architecture.md#Frontend Architecture - Component Template Example]

```typescript
// components/bunker/BunkerConfigOverride.tsx
import React, { useState, useEffect } from 'react';
import { Bunker, GlobalConfig, BunkerConfigUpdate } from '@/types';
import * as bunkerService from '@/services/bunker.service';
import * as configService from '@/services/config.service';
import { ConfigToggleField } from './ConfigToggleField';

interface BunkerConfigOverrideProps {
  bunker: Bunker;
  onUpdate: (updatedBunker: Bunker) => void;
}

export const BunkerConfigOverride: React.FC<BunkerConfigOverrideProps> = ({
  bunker,
  onUpdate
}) => {
  const [globalConfig, setGlobalConfig] = useState<GlobalConfig | null>(null);
  const [useCustomWindThreshold, setUseCustomWindThreshold] = useState(
    bunker.wind_threshold_mph !== null
  );
  const [windThreshold, setWindThreshold] = useState(
    bunker.wind_threshold_mph?.toString() || ''
  );
  const [electricityCost, setElectricityCost] = useState(
    bunker.electricity_cost_kwh.toString()
  );
  const [isSaving, setIsSaving] = useState(false);
  const [errors, setErrors] = useState<{ wind?: string; cost?: string }>({});

  useEffect(() => {
    const fetchGlobalConfig = async () => {
      try {
        const config = await configService.getGlobalConfig();
        setGlobalConfig(config);
      } catch (error) {
        console.error('Failed to load global config:', error);
      }
    };
    fetchGlobalConfig();
  }, []);

  const validate = (): boolean => {
    const newErrors: { wind?: string; cost?: string } = {};

    if (useCustomWindThreshold) {
      const wind = parseFloat(windThreshold);
      if (isNaN(wind) || wind < 0) {
        newErrors.wind = 'Wind threshold must be a positive number';
      }
    }

    const cost = parseFloat(electricityCost);
    if (isNaN(cost) || cost < 0) {
      newErrors.cost = 'Electricity cost must be a positive number';
    }

    setErrors(newErrors);
    return Object.keys(newErrors).length === 0;
  };

  const handleSave = async () => {
    if (!validate()) return;

    setIsSaving(true);

    try {
      const updates: BunkerConfigUpdate = {
        wind_threshold_mph: useCustomWindThreshold ? parseFloat(windThreshold) : null,
        electricity_cost_kwh: parseFloat(electricityCost)
      };

      const updatedBunker = await bunkerService.updateBunkerConfig(bunker.id, updates);
      onUpdate(updatedBunker);
      // Show success toast
    } catch (error) {
      console.error('Failed to save config:', error);
      // Show error toast
    } finally {
      setIsSaving(false);
    }
  };

  if (!globalConfig) {
    return <div>Loading configuration...</div>;
  }

  const effectiveWindThreshold = useCustomWindThreshold
    ? parseFloat(windThreshold)
    : globalConfig.default_wind_threshold_mph;

  return (
    <div className="bg-white rounded-lg shadow-lg p-6">
      <h3 className="text-xl font-semibold mb-4">Configuration Overrides</h3>
      <p className="text-sm text-gray-600 mb-6">
        Override global settings for this bunker. Unchecked values will use system defaults.
      </p>

      {/* Wind Threshold Override */}
      <div className="mb-6 border-b pb-6">
        <div className="flex items-start justify-between mb-4">
          <div className="flex-1">
            <label className="flex items-center space-x-2 mb-2">
              <input
                type="checkbox"
                checked={useCustomWindThreshold}
                onChange={(e) => {
                  setUseCustomWindThreshold(e.target.checked);
                  if (!e.target.checked) {
                    setWindThreshold('');
                    setErrors({ ...errors, wind: undefined });
                  }
                }}
                className="w-4 h-4"
              />
              <span className="font-medium text-gray-900">
                Custom Wind Threshold
              </span>
            </label>
            <p className="text-sm text-gray-500 ml-6">
              Global default: {globalConfig.default_wind_threshold_mph} mph
            </p>
          </div>

          {useCustomWindThreshold ? (
            <span className="px-3 py-1 bg-blue-100 text-blue-800 text-xs rounded-full">
              Custom
            </span>
          ) : (
            <span className="px-3 py-1 bg-gray-100 text-gray-600 text-xs rounded-full">
              Global
            </span>
          )}
        </div>

        {useCustomWindThreshold && (
          <div className="ml-6">
            <div className="flex items-center space-x-2">
              <input
                type="number"
                step="0.1"
                value={windThreshold}
                onChange={(e) => setWindThreshold(e.target.value)}
                placeholder={globalConfig.default_wind_threshold_mph.toString()}
                className="w-32 px-3 py-2 border rounded-lg focus:ring-2 focus:ring-blue-500"
              />
              <span className="text-gray-600">mph</span>
            </div>
            {errors.wind && <p className="text-red-500 text-sm mt-1">{errors.wind}</p>}
            <p className="text-xs text-gray-500 mt-2">
              Fans will shut down when wind exceeds this threshold
            </p>
          </div>
        )}

        <div className="mt-4 p-3 bg-blue-50 rounded-lg">
          <p className="text-sm text-blue-900">
            <strong>Current Effective Value:</strong> {effectiveWindThreshold} mph
          </p>
        </div>
      </div>

      {/* Electricity Cost */}
      <div className="mb-6">
        <label className="block font-medium text-gray-900 mb-2">
          Electricity Cost ($/kWh)
        </label>
        <p className="text-sm text-gray-500 mb-3">
          Global default: ${globalConfig.default_electricity_cost_kwh.toFixed(3)}/kWh
        </p>
        <div className="flex items-center space-x-2">
          <span className="text-gray-600">$</span>
          <input
            type="number"
            step="0.001"
            value={electricityCost}
            onChange={(e) => setElectricityCost(e.target.value)}
            className="w-32 px-3 py-2 border rounded-lg focus:ring-2 focus:ring-blue-500"
          />
          <span className="text-gray-600">per kWh</span>
        </div>
        {errors.cost && <p className="text-red-500 text-sm mt-1">{errors.cost}</p>}
        <p className="text-xs text-gray-500 mt-2">
          Used for calculating energy savings for this bunker
        </p>
      </div>

      {/* Save Button */}
      <div className="flex justify-end">
        <button
          onClick={handleSave}
          disabled={isSaving}
          className="px-6 py-2 bg-blue-600 text-white rounded-lg hover:bg-blue-700 disabled:opacity-50"
        >
          {isSaving ? 'Saving...' : 'Save Configuration'}
        </button>
      </div>

      {/* Help Text */}
      <div className="mt-6 p-4 bg-gray-50 rounded-lg">
        <h4 className="text-sm font-semibold text-gray-900 mb-2">About Overrides</h4>
        <ul className="text-sm text-gray-700 space-y-1 list-disc list-inside">
          <li>Custom wind thresholds allow fine-tuning for specific bunker locations</li>
          <li>Higher risk bunkers can use lower thresholds (fans stay on longer)</li>
          <li>Electricity costs vary by region and provider</li>
          <li>Accurate costs ensure proper energy savings calculations</li>
        </ul>
      </div>
    </div>
  );
};
```

### Service Functions

```typescript
// services/bunker.service.ts
export async function updateBunkerConfig(
  id: string,
  config: BunkerConfigUpdate
): Promise<Bunker> {
  const response = await api.put<Bunker>(`/bunkers/${id}`, config);
  return response.data;
}

// services/config.service.ts
import api from './api';
import { GlobalConfig } from '@/types';

export async function getGlobalConfig(): Promise<GlobalConfig> {
  const response = await api.get<GlobalConfig>('/config');
  return response.data;
}

export async function updateGlobalConfig(updates: Partial<GlobalConfig>): Promise<GlobalConfig> {
  const response = await api.put<GlobalConfig>('/config', updates);
  return response.data;
}
```

### Custom Hook for Global Config

```typescript
// hooks/useGlobalConfig.ts
import { useState, useEffect } from 'react';
import { GlobalConfig } from '@/types';
import * as configService from '@/services/config.service';

export function useGlobalConfig() {
  const [config, setConfig] = useState<GlobalConfig | null>(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState<Error | null>(null);

  useEffect(() => {
    const fetchConfig = async () => {
      try {
        const data = await configService.getGlobalConfig();
        setConfig(data);
        setError(null);
      } catch (err) {
        setError(err as Error);
      } finally {
        setLoading(false);
      }
    };

    fetchConfig();
  }, []);

  return { config, loading, error };
}
```

   - Test non-numeric inputs → verify validation

   - Verify "Custom" badge shows when override active
   - Verify "Global" badge shows when using defaults
   - Verify current effective value displayed prominently

6. **Integration:**
   - Verify control logic respects custom thresholds
   - Verify energy savings use custom electricity cost
   - Test with multiple bunkers (some custom, some global)

**Test Scenarios:**
- Bunker A: Custom threshold 12 mph, custom cost $0.15/kWh
- Bunker B: Global threshold (15 mph), custom cost $0.10/kWh
- Bunker C: All global defaults
- Verify each bunker behaves according to its configuration
