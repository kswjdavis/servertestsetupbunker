# Story 3.9: Responsive Layout and Mobile Support

## Status
Draft

## Story
**As a** web UI operator,
**I want** UI that works well on tablets and desktop,
**so that** I can access the system from various devices in the office or field.

## Acceptance Criteria

1. Layout responsive from 768px (tablet) to 1920px (desktop)
2. Header navigation adapts to screen size
3. Map dashboard usable on tablet (min 768px wide)
4. Tables scroll horizontally on smaller screens
5. Forms stack vertically on tablet
6. Touch-friendly buttons (min 44x44px)
7. Emergency buttons remain accessible on all screen sizes
8. No horizontal scrolling on any screen size
9. Tested on iPad and desktop browsers
10. Mobile phone (< 768px) shows simplified view or message

### Responsive Header Navigation

Adapt header for different screen sizes:

```typescript
// components/layout/Header.tsx
export const Header: React.FC = () => {
  const [mobileMenuOpen, setMobileMenuOpen] = useState(false);

  return (
    <header className="bg-gray-800 text-white">
      <div className="container mx-auto px-4 py-3 flex justify-between items-center">
        {/* Logo */}
        <h1 className="text-xl lg:text-2xl font-bold">Bunker Colab</h1>

        {/* Desktop Navigation (hidden on mobile) */}
        <nav className="hidden md:flex gap-4">
          <NavLink to="/dashboard">Dashboard</NavLink>
          <NavLink to="/devices">Devices</NavLink>
          <NavLink to="/settings">Settings</NavLink>
        </nav>

        {/* Emergency Button (always visible) */}
        <div className="hidden md:block">
          <EmergencyButton scope="global" />
        </div>

        {/* Mobile Menu Button (shown only on mobile) */}
        <button
          className="md:hidden min-h-[44px] min-w-[44px]"
          onClick={() => setMobileMenuOpen(!mobileMenuOpen)}
        >
          <MenuIcon />
        </button>
      </div>

      {/* Mobile Menu Dropdown */}
      {mobileMenuOpen && (
        <div className="md:hidden bg-gray-700 p-4">
          {/* Navigation links stacked vertically */}
          <EmergencyButton scope="global" />
        </div>
      )}
    </header>
  );
};
```

### Touch-Friendly Buttons

Ensure all interactive elements meet minimum size:
[Source: architecture.md#Frontend Architecture - Component Template]

```typescript
// components/common/Button.tsx
interface ButtonProps {
  children: React.ReactNode;
  onClick?: () => void;
  variant?: 'primary' | 'secondary' | 'danger';
  disabled?: boolean;
}

export const Button: React.FC<ButtonProps> = ({
  children,
  onClick,
  variant = 'primary',
  disabled = false
}) => {
  const baseClasses = 'min-h-[44px] min-w-[44px] px-4 py-2 rounded font-semibold transition';

  const variantClasses = {
    primary: 'bg-blue-600 hover:bg-blue-700 text-white',
    secondary: 'bg-gray-200 hover:bg-gray-300 text-gray-800',
    danger: 'bg-red-600 hover:bg-red-700 text-white'
  };

  return (
    <button
      onClick={onClick}
      disabled={disabled}
      className={`${baseClasses} ${variantClasses[variant]} ${disabled ? 'opacity-50 cursor-not-allowed' : ''}`}
    >
      {children}
    </button>
  );
};
```

### Responsive Form Layouts

    <FormField label="Wind Threshold" {...} />
    <FormField label="Electricity Cost" {...} />
  </div>

  {/* Buttons stack on mobile, horizontal on tablet */}
  <div className="flex flex-col md:flex-row justify-end gap-3 mt-6">
    <Button variant="secondary">Reset</Button>
    <Button variant="primary">Save</Button>
  </div>
</form>
```

  >
    {/* Map layers */}

```

**Tablet Considerations:**
- Map height: full viewport height minus header
- Zoom controls: large enough for touch (default Leaflet controls are adequate)
- Marker size: 32x32px minimum for easy tapping
- Popup content: readable at tablet zoom levels

### Testing

[Source: architecture.md#Testing Strategy]

**Manual Testing Required (POC Scope):**
- Test all pages at 768px, 1024px, 1280px, and 1920px viewports
- Verify no horizontal scrolling at any viewport size
- Test touch interactions on physical iPad (if available)
- Verify buttons are easily tappable (min 44x44px)
- Test table horizontal scrolling on 768px viewport
- Verify map usability on tablet
- Test emergency buttons accessible on all screen sizes
- Verify mobile warning displays on screens < 768px

**Test Scenario:**
1. Open Chrome DevTools → Device Toolbar
2. Test Dashboard at 768px viewport:
   - Verify header navigation adapts
   - Verify emergency button visible and tappable
   - Verify map renders correctly
   - Verify no horizontal scrolling
3. Test Device List at 768px:
   - Verify table scrolls horizontally if needed
   - Verify buttons are touch-friendly (44x44px)
4. Test Settings at 768px:
   - Verify form fields stack vertically
   - Verify buttons stack or go horizontal (flex-wrap)
5. Test Bunker Detail at 768px:
   - Verify fan grid adapts to screen width
   - Verify emergency button accessible
6. Repeat tests at 1024px, 1280px, 1920px
7. Test on physical tablet (iPad) if available
8. Test at 375px (mobile phone) → verify warning displays
