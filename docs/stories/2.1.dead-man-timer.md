# Story 2.1: ESP32 Dead-Man Timer Implementation

## Status
Ready for Dev

## Story
**As an** ESP32 device,
**I want** a 5-minute countdown timer that resets when server commands arrive,
**so that** fans automatically turn ON if server communication is lost (fail-safe).

## Acceptance Criteria

1. Timer initializes to 300 seconds (5 minutes) on boot
2. Timer decrements every second in FreeRTOS task
3. Timer resets to 300 when server sends reset_countdown=true
4. When timer reaches 0, relay_force_on() is called
5. Timer state is thread-safe (atomic operations or mutex)
6. Timer remaining value is readable by status reporting task
7. Timer expiration logs "Dead-man timer expired - entering fail-safe" (FR17, FR18, FR19)
8. Timer does NOT reset automatically - only on server command
9. Timer continues running even after expiration (for monitoring)
10. Unit tests verify timer behavior

## Dev Notes

### Timer Implementation (FreeRTOS)

```c
// deadman_timer.h
#ifndef DEADMAN_TIMER_H
#define DEADMAN_TIMER_H

#include <stdint.h>
#include <stdbool.h>

#define DEADMAN_TIMER_INITIAL_VALUE 300  // 5 minutes

void deadman_timer_init(void);
void deadman_timer_reset(void);
uint32_t deadman_timer_get_remaining(void);
bool deadman_timer_is_expired(void);

#endif
```

```c
// deadman_timer.c
#include "deadman_timer.h"
#include "relay_controller.h"
#include "esp_log.h"
#include "freertos/FreeRTOS.h"
#include "freertos/task.h"

static const char *TAG = "deadman_timer";

typedef struct {
    uint32_t countdown_seconds;
    bool expired;
    SemaphoreHandle_t mutex;
} deadman_timer_state_t;

static deadman_timer_state_t timer_state = {
    .countdown_seconds = DEADMAN_TIMER_INITIAL_VALUE,
    .expired = false,
    .mutex = NULL
};

static void deadman_timer_task(void *pvParameters) {
    while (1) {
        vTaskDelay(pdMS_TO_TICKS(1000));  // 1 second

        xSemaphoreTake(timer_state.mutex, portMAX_DELAY);

        if (timer_state.countdown_seconds > 0) {
            timer_state.countdown_seconds--;

            if (timer_state.countdown_seconds == 0 && !timer_state.expired) {
                ESP_LOGE(TAG, "⚠ DEAD-MAN TIMER EXPIRED - ENTERING FAIL-SAFE MODE");
                relay_force_on();
                timer_state.expired = true;
            }
        }

        xSemaphoreGive(timer_state.mutex);
    }
}

void deadman_timer_init(void) {
    timer_state.mutex = xSemaphoreCreateMutex();
    xTaskCreate(deadman_timer_task, "deadman_timer", 2048, NULL, 5, NULL);
    ESP_LOGI(TAG, "Dead-man timer initialized: %d seconds", DEADMAN_TIMER_INITIAL_VALUE);
}

void deadman_timer_reset(void) {
    xSemaphoreTake(timer_state.mutex, portMAX_DELAY);
    timer_state.countdown_seconds = DEADMAN_TIMER_INITIAL_VALUE;
    timer_state.expired = false;
    xSemaphoreGive(timer_state.mutex);

    ESP_LOGI(TAG, "Dead-man timer reset to %d seconds", DEADMAN_TIMER_INITIAL_VALUE);
}

uint32_t deadman_timer_get_remaining(void) {
    xSemaphoreTake(timer_state.mutex, portMAX_DELAY);
    uint32_t remaining = timer_state.countdown_seconds;
    xSemaphoreGive(timer_state.mutex);
    return remaining;
}

bool deadman_timer_is_expired(void) {
    xSemaphoreTake(timer_state.mutex, portMAX_DELAY);
    bool expired = timer_state.expired;
    xSemaphoreGive(timer_state.mutex);
    return expired;
}
```

### Integration with Server Response

When server response arrives with `reset_countdown: true`:
```c
void handle_server_response(server_decision_t decision) {
    if (decision.reset_countdown) {
        deadman_timer_reset();
    }

    if (!decision.shutdown_allowed) {
        relay_force_on();
    }
}
```
