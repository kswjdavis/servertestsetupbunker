# Story 3.8: Real-Time Status Updates via Polling

## Status
Ready for Dev

## Story
**As a** web UI operator,
**I want** UI to automatically refresh with latest device and bunker status,
**so that** I see near real-time updates without manual refresh.

## Acceptance Criteria

1. Custom usePolling hook for reusable polling logic
2. Dashboard polls bunkers every 3 seconds
3. Device list polls devices every 5 seconds
4. Bunker detail polls bunker status every 2 seconds
5. Polling pauses when tab is not visible (Page Visibility API)
6. Polling resumes when tab becomes visible
7. Cleanup intervals on component unmount
8. Error handling doesn't break polling loop
9. Visual indicator when data is updating (subtle)
10. No performance degradation after extended use

### Custom Polling Hook

Implement reusable polling with cleanup:
[Source: architecture.md#Frontend Architecture - Custom Hooks - Polling]

```typescript
// hooks/usePoll.ts
import { useEffect, useRef } from 'react';

export function usePoll(
  callback: () => void | Promise<void>,
  interval: number,
  enabled: boolean = true
) {
  const savedCallback = useRef(callback);

  // Update callback ref if it changes
  useEffect(() => {
    savedCallback.current = callback;
  }, [callback]);

  useEffect(() => {
    if (!enabled) return;

    // Call immediately on mount
    savedCallback.current();

    // Then poll at interval
    const id = setInterval(() => {
      savedCallback.current();
    }, interval);

    // Cleanup on unmount
    return () => clearInterval(id);
  }, [interval, enabled]);
}
```

### Page Visibility Integration

Pause polling when tab is not visible to save resources:

```typescript
// hooks/usePageVisibility.ts
import { useState, useEffect } from 'react';

export function usePageVisibility(): boolean {
  const [isVisible, setIsVisible] = useState(!document.hidden);

  useEffect(() => {
    const handleVisibilityChange = () => {
      setIsVisible(!document.hidden);
    };

    document.addEventListener('visibilitychange', handleVisibilityChange);

    return () => {
      document.removeEventListener('visibilitychange', handleVisibilityChange);
    };
  }, []);

  return isVisible;
}
```

### Integration Example: Dashboard

```typescript
// pages/DashboardPage.tsx
import React, { useState, useCallback } from 'react';
import { usePoll } from '@/hooks/usePoll';
import { usePageVisibility } from '@/hooks/usePageVisibility';
import * as bunkerService from '@/services/bunker.service';

export const DashboardPage: React.FC = () => {
  const [bunkers, setBunkers] = useState<Bunker[]>([]);
  const [loading, setLoading] = useState(true);
  const [updating, setUpdating] = useState(false);
  const isVisible = usePageVisibility();

  const fetchBunkers = useCallback(async () => {
    try {
      setUpdating(true);
      const data = await bunkerService.listBunkers();
      setBunkers(data);
      setLoading(false);
    } catch (error) {
      console.error('Failed to fetch bunkers:', error);
      // Don't break polling loop on error
    } finally {
      setUpdating(false);
    }
  }, []);

  // Poll every 3 seconds, but only when tab is visible
  usePoll(fetchBunkers, 3000, isVisible);

  return (
    <div>
      {updating && <UpdateIndicator />}
      {/* Dashboard content */}
    </div>
  );
};
```

### Integration Example: Bunker Detail

```typescript
// pages/BunkerDetailPage.tsx
export const BunkerDetailPage: React.FC = () => {
  const { bunkerId } = useParams();
  const [bunkerStatus, setBunkerStatus] = useState<BunkerStatus | null>(null);
  const isVisible = usePageVisibility();

  const fetchBunkerStatus = useCallback(async () => {
    if (!bunkerId) return;

      const data = await bunkerService.getBunkerStatus(bunkerId);
      setBunkerStatus(data);
    } catch (error) {
      console.error('Failed to fetch bunker status:', error);
    }
  }, [bunkerId]);

  // Poll every 2 seconds for fastest updates (AC: 4)
  usePoll(fetchBunkerStatus, 2000, isVisible);

  return <div>{/* Bunker detail */}</div>;
};
```

```typescript
    setError(null);
  } catch (error) {
    // Log error but don't throw

```

### Performance Considerations

Prevent memory leaks and performance degradation:
[Source: architecture.md#Frontend Architecture - Custom Hooks]

**Best Practices:**
- Use `useCallback` for fetch functions to prevent unnecessary effect re-runs
- Clear intervals on component unmount (handled by `usePoll`)
- Pause polling when tab is not visible (Page Visibility API)
- Use refs for callback to avoid recreating intervals
- Don't create new objects/arrays on every poll (causes unnecessary re-renders)

**Memory Leak Prevention:**
```typescript
useEffect(() => {
  const id = setInterval(() => {
    // ...
  }, interval);

  // CRITICAL: Always cleanup
  return () => clearInterval(id);
}, [interval]);
```
