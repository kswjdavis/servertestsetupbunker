# Story 3.5: Device List and Management

## Status
Ready for Dev

## Story
**As a** system administrator,
**I want** to view all provisioned devices and their status,
**so that** I can monitor device health and deprovision devices if needed.

## Acceptance Criteria

1. Table showing all devices with: ID, Bunker, Fan Position, Status (online/offline), Last Seen
2. Online/offline indicator based on last_seen timestamp (>2 min = offline)
3. Search/filter by bunker name
4. Click row to see device details
5. Delete button to deprovision device (with confirmation)
6. Poll GET /api/v1/devices every 5 seconds
7. Status indicators colored: green (online), red (offline)
8. Responsive table design
9. Empty state when no devices
10. Loading skeleton while fetching

```typescript
// pages/DeviceListPage.tsx
import React, { useState } from 'react';
import { usePoll } from '@/hooks/usePoll';
import * as deviceService from '@/services/device.service';

export const DeviceListPage: React.FC = () => {
  const [devices, setDevices] = useState<Device[]>([]);
  const [loading, setLoading] = useState(true);
  const [searchTerm, setSearchTerm] = useState('');

  const fetchDevices = async () => {
    try {
      const data = await deviceService.listDevices();
      setDevices(data);
      setLoading(false);
    } catch (error) {
      console.error('Failed to fetch devices:', error);
    }
  };

  // Poll every 5 seconds (AC: 6)
  usePoll(fetchDevices, 5000);

  // Filter devices by bunker name
  const filteredDevices = devices.filter(device =>

  );

  return (
    <div className="container mx-auto p-6">
      <h1 className="text-2xl font-bold mb-4">Device Management</h1>
      {/* Search input, table, etc. */}
    </div>
  );
};
```

### Online/Offline Logic

Implement status calculation based on last_seen timestamp:
[Source: architecture.md#Data Models - Device]

```typescript
// utils/deviceHelpers.ts
export function isDeviceOnline(lastSeen: string | null): boolean {
  if (!lastSeen) return false;

  const lastSeenDate = new Date(lastSeen);
  const now = new Date();
  const diffMinutes = (now.getTime() - lastSeenDate.getTime()) / 1000 / 60;

  return diffMinutes <= 2;  // Online if last seen within 2 minutes
}
```

### Polling Strategy

Use custom polling hook for real-time updates:
[Source: architecture.md#Frontend Architecture - Custom Hooks - Polling]

```typescript
// hooks/usePoll.ts
import { useEffect, useRef } from 'react';

export function usePoll(callback: () => void, interval: number, enabled: boolean = true) {
  const savedCallback = useRef(callback);

  useEffect(() => {
    savedCallback.current = callback;
  }, [callback]);

  useEffect(() => {
    if (!enabled) return;

    // Call immediately
    savedCallback.current();

    // Then poll at interval
    const id = setInterval(() => savedCallback.current(), interval);
    return () => clearInterval(id);
  }, [interval, enabled]);
}
```
