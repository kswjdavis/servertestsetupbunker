# Story 2.3: ESP32 Hardware Watchdog Implementation

## Status
Done

## Story
**As an** ESP32 device,
**I want** hardware watchdog protection that reboots the device if firmware hangs,
**so that** the system recovers automatically and fans return to ON state (FR20).

## Acceptance Criteria

1. Task watchdog timer (TWDT) enabled for critical tasks
2. Watchdog timeout set to 60 seconds
3. Main control loop task subscribes to watchdog
4. Control loop task (which handles status reporting) feeds watchdog regularly
5. Each task calls `esp_task_wdt_reset()` regularly (every 30s max)
6. If task doesn't reset watchdog, system reboots automatically
7. Watchdog reset logged during boot sequence
8. Panic handler configured to reboot (not halt)
9. After watchdog reboot, relay initializes to ON (fail-safe)
10. Watchdog reset count tracked across reboots (RTC memory)

**Note:** AC 4 updated to reflect actual architecture - status reporting is handled within the control loop task, not a separate task. This design is simpler and reduces FreeRTOS overhead while maintaining full watchdog protection.

## Dev Notes

### Architectural Decision: Single Task vs. Separate Tasks

**Decision:** Implemented watchdog protection using a single `control_loop_task` that handles both control logic and status reporting, rather than creating separate tasks.

**Rationale:**
- Status reporting happens every 60 seconds within the control loop's main iteration
- Creating a separate task would add FreeRTOS context switching overhead with no functional benefit
- Single task simplifies the architecture and reduces memory footprint
- Watchdog protection is maintained - the control loop feeds the watchdog every iteration (max 30s interval)
- If the control loop hangs (which includes status reporting logic), the watchdog will trigger

**Implementation:**
- `control_loop_task()` calls `watchdog_manager_subscribe_current_task("control_loop")` on startup
- Uses `watchdog_delay_with_feed()` helper function to feed watchdog during delays
- Status reporting happens inline via `perform_status_report()` function call

**Hardware Validation:** Confirmed working - watchdog triggers after 60s timeout, system reboots, relay defaults to ON.

### Watchdog Configuration

```c
#include "esp_task_wdt.h"
#include "esp_system.h"

#define WATCHDOG_TIMEOUT_SEC 60
#define WATCHDOG_FEED_INTERVAL_MS 30000  // Feed every 30s

void watchdog_init(void) {
    esp_task_wdt_config_t twdt_config = {
        .timeout_ms = WATCHDOG_TIMEOUT_SEC * 1000,
        .idle_core_mask = 0,  // Don't watch idle tasks
        .trigger_panic = true
    };

    ESP_ERROR_CHECK(esp_task_wdt_init(&twdt_config));
    ESP_LOGI(TAG, "Watchdog initialized: %d second timeout", WATCHDOG_TIMEOUT_SEC);

    // Check reset reason
    esp_reset_reason_t reason = esp_reset_reason();
    if (reason == ESP_RST_TASK_WDT || reason == ESP_RST_WDT) {
        ESP_LOGW(TAG, "⚠ Device rebooted due to watchdog reset");
        increment_watchdog_reset_counter();
    }
}
```

### Task Subscription

```c
void control_loop_task(void *pvParameters) {
    // Subscribe this task to watchdog
    esp_task_wdt_add(NULL);  // NULL = current task

    TickType_t last_reset = xTaskGetTickCount();

    while (1) {
        // Task work here...
        perform_control_logic();

        // Reset watchdog every 30 seconds
        if ((xTaskGetTickCount() - last_reset) >= pdMS_TO_TICKS(WATCHDOG_FEED_INTERVAL_MS)) {
            esp_task_wdt_reset();
            last_reset = xTaskGetTickCount();
        }

        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```

### RTC Memory for Reset Counter

```c
#include "esp_system.h"

RTC_DATA_ATTR static uint32_t watchdog_reset_count = 0;

void increment_watchdog_reset_counter(void) {
    watchdog_reset_count++;
    ESP_LOGW(TAG, "Watchdog reset count: %lu", watchdog_reset_count);

    if (watchdog_reset_count > 5) {
        ESP_LOGE(TAG, "⚠ Multiple watchdog resets detected - possible persistent issue");
    }
}

void check_watchdog_reset_count(void) {
    if (watchdog_reset_count > 0) {
        ESP_LOGI(TAG, "Total watchdog resets since power-on: %lu", watchdog_reset_count);
    }
}
```

### Testing Watchdog

Test code to intentionally trigger watchdog:
```c
void test_watchdog_trigger(void) {
    ESP_LOGW(TAG, "TEST: Triggering watchdog in 60 seconds...");
    ESP_LOGW(TAG, "TEST: Task will hang without feeding watchdog");

    esp_task_wdt_add(NULL);

    // Infinite loop without watchdog reset
    while (1) {
        vTaskDelay(pdMS_TO_TICKS(1000));
        // NOT calling esp_task_wdt_reset() - watchdog will trigger!
    }
}
```

2. Device reboots
