# Story 4.7: Enhanced Fan Layout Visualization

## Status
Ready for Dev

## Story
**As a** web UI operator,
**I want** visually appealing fan layout that clearly shows fan positions and status,
**so that** I can quickly understand bunker configuration and identify issues.

## Acceptance Criteria

1. Fan diagram uses SVG for scalable graphics
2. Fans arranged in grid matching actual bunker layout
3. Each fan shows position number clearly
4. Hover shows detailed info: Device ID, MAC, Uptime, RSSI
5. Click fan for device details
6. Animated status transitions (smooth color changes)
7. Legend explaining colors
8. Works well from 4 fans to 10 fans per bunker
9. Print-friendly styling
10. Accessible (screen reader support for fan status)

### SVG Fan Visualization

[Source: architecture.md#Frontend Architecture - Component Template Example]

```typescript
// components/bunker/FanSVG.tsx
import React from 'react';

interface FanSVGProps {
  position: number;
  status: 'online-on' | 'online-off' | 'offline';
  size?: number;
  onClick?: () => void;
}

export const FanSVG: React.FC<FanSVGProps> = ({
  position,
  status,
  size = 80,
  onClick
}) => {
  const colors = {
    'online-on': '#22c55e',    // Green
    'online-off': '#3b82f6',   // Blue
    'offline': '#ef4444'       // Red
  };

  const color = colors[status];

  return (
    <svg
      width={size}
      height={size}
      viewBox="0 0 100 100"
      onClick={onClick}
      className="cursor-pointer transition-all duration-300 hover:scale-110"
      role="button"
      aria-label={`Fan ${position}, ${status.replace('-', ' ')}`}
      tabIndex={0}
    >
      {/* Fan circle */}
      <circle
        cx="50"
        cy="50"
        r="45"
        fill={color}
        stroke="#1f2937"
        strokeWidth="2"
        className="transition-all duration-500"
      />

      {/* Fan blades (rotating animation for ON status) */}
      <g
        className={status === 'online-on' ? 'animate-spin origin-center' : ''}
        style={{ transformOrigin: '50% 50%' }}
      >
        {[0, 120, 240].map(angle => (
          <path
            key={angle}
            d="M 50 50 L 50 20 Q 60 30 50 40 Z"
            fill="rgba(255, 255, 255, 0.7)"
            transform={`rotate(${angle} 50 50)`}
          />
        ))}
      </g>

      {/* Position number */}
      <text
        x="50"
        y="60"
        textAnchor="middle"
        fontSize="24"
        fontWeight="bold"
        fill="#fff"
      >
        {position}
      </text>

      {/* Status indicator dot */}
      <circle
        cx="80"
        cy="20"
        r="8"
        fill={status === 'offline' ? '#fbbf24' : '#10b981'}
        stroke="#fff"
        strokeWidth="2"
      />
    </svg>
  );
};
```

// components/bunker/FanTooltip.tsx
import React from 'react';
import { Popover } from '@headlessui/react';
import { FanStatus } from '@/types';
import { formatDuration } from '@/utils/formatters';

interface FanTooltipProps {

  children: React.ReactNode;

export const FanTooltip: React.FC<FanTooltipProps> = ({ fan, children }) => {
  return (
    <Popover className="relative">
      <Popover.Button as="div">{children}</Popover.Button>

        <div className="space-y-2">
          <div className="flex justify-between">
            <span className="text-gray-400">Device ID:</span>
            <span className="font-mono text-xs">{fan.device_id.slice(0, 8)}...</span>
          </div>
          <div className="flex justify-between">
            <span className="text-gray-400">MAC Address:</span>
            <span className="font-mono text-xs">{fan.mac_address}</span>
          </div>
          <div className="flex justify-between">
            <span className="text-gray-400">Uptime:</span>
            <span>{formatDuration(fan.uptime_seconds)}</span>
          </div>
          <div className="flex justify-between">
            <span className="text-gray-400">WiFi Signal:</span>
            <span>{fan.wifi_rssi} dBm</span>
          </div>
          <div className="flex justify-between">
            <span className="text-gray-400">Relay State:</span>

          )}

    </Popover>
  );
};

### Layout Component

```typescript
// components/bunker/FanLayoutVisualization.tsx
import React from 'react';
import { useNavigate } from 'react-router-dom';
import { FanStatus } from '@/types';
import { FanSVG } from './FanSVG';
import { FanTooltip } from './FanTooltip';
import { StatusLegend } from './StatusLegend';

interface FanLayoutVisualizationProps {
  devices: FanStatus[];
  fanCount: number;
}

export const FanLayoutVisualization: React.FC<FanLayoutVisualizationProps> = ({
  devices,
  fanCount
}) => {
  const navigate = useNavigate();

  // Calculate responsive grid columns based on fan count
  const getGridCols = (count: number): string => {
    if (count <= 4) return 'grid-cols-2';
    if (count <= 6) return 'grid-cols-3';
    if (count <= 9) return 'grid-cols-3 lg:grid-cols-3';
    return 'grid-cols-3 lg:grid-cols-4';
  };

  const getFanStatus = (device: FanStatus): 'online-on' | 'online-off' | 'offline' => {
    if (!device.is_online) return 'offline';
    return device.relay_state === 'ON' ? 'online-on' : 'online-off';
  };

  return (
    <div className="bg-white rounded-lg shadow-lg p-6">
      <div className="flex items-center justify-between mb-6">
        <h3 className="text-xl font-semibold">Fan Layout</h3>
        <StatusLegend />
      </div>

      <div className={`grid ${getGridCols(fanCount)} gap-6 justify-items-center`}>
        {Array.from({ length: fanCount }, (_, i) => i + 1).map(position => {
          const device = devices.find(d => d.fan_position === position);

          if (!device) {
            // Empty slot (device not provisioned yet)
            return (
              <div
                key={position}
                className="flex items-center justify-center w-20 h-20 border-2 border-dashed border-gray-300 rounded-full"
                aria-label={`Fan ${position} not provisioned`}
              >
                <span className="text-gray-400 text-sm">#{position}</span>
              </div>
            );
          }

          return (
            <FanTooltip key={device.device_id} fan={device}>
              <FanSVG
                position={position}
                status={getFanStatus(device)}
                onClick={() => navigate(`/devices/${device.device_id}`)}
              />
            </FanTooltip>
          );
        })}
      </div>
    </div>
  );
};
```

### Accessibility (WCAG AA)

[Source: architecture.md#Tech Stack - UI Component Library]

**ARIA Labels:**
- Each fan has `aria-label` describing position and status
- `role="button"` and `tabIndex={0}` for keyboard navigation
- Screen reader announces: "Fan 3, online running"

**Keyboard Navigation:**
```typescript
const handleKeyPress = (e: React.KeyboardEvent, deviceId: string) => {
  if (e.key === 'Enter' || e.key === ' ') {
    e.preventDefault();
    navigate(`/devices/${deviceId}`);
  }
};
```

### Testing

[Source: architecture.md#Testing Strategy - Frontend Tests]

**Manual Testing (POC Scope):**

1. **Visual Layout:**
   - Test with 4, 6, 9, and 10 fans
   - Verify grid adapts responsively
   - Check spacing and alignment

2. **Animations:**
   - Verify fans with `relay_state='ON'` show spinning blades
   - Test color transitions when status changes
   - Check hover scale animation

3. **Tooltips:**
   - Hover each fan → verify tooltip appears
   - Check all device details display correctly
   - Test tooltip positioning (doesn't go off-screen)

4. **Accessibility:**
   - Navigate with keyboard (Tab key)
   - Activate with Enter/Space keys
   - Test with screen reader (VoiceOver/NVDA)
   - Verify ARIA labels are read correctly

5. **Print:**
   - Print preview the page
   - Verify colors render correctly
   - Check layout doesn't break

6. **Click Navigation:**
   - Click each fan → verify navigates to device detail page
   - Test with offline fans (should still navigate)

**Test Scenarios:**
- 4 fans: 2 online-on, 1 online-off, 1 offline
- 10 fans: Mixed statuses in all positions
- Browser zoom 50%, 100%, 150%
- Print to PDF and verify quality
