# Story 2.5: Control Logic Engine (Backend)

## Status
Done

## Story
**As a** backend server,
**I want** centralized control logic that determines when fans can shut down based on wind conditions,
**so that** the server makes consistent, safe shutdown decisions for all devices (FR2).

## Acceptance Criteria

1. ControlLogicEngine class with should_shutdown_fans() method
2. Decision based on: wind speed >= threshold AND no active overrides AND no emergency mode
3. Returns ShutdownDecision object with: shutdown_allowed (bool), reset_countdown (bool), reason (string)
4. Wind threshold compared against wind_speed_mph from WeatherService
5. Emergency mode check per-bunker and global
6. Time window override check (active NOW for this bunker)
7. Default decision is shutdown_allowed=False (fail-safe)
8. All logic unit-tested with pytest
9. Decision logged at INFO level for audit trail
10. Integrated into POST /api/v1/control/status endpoint

from app.schemas.control import ShutdownDecision
from app.services.weather_service import weather_service
from app.repositories.bunker_repository import BunkerRepository

class ControlLogicEngine:
    async def should_shutdown_fans(self, device_id: UUID, session: AsyncSession) -> ShutdownDecision:
        # Get device and bunker
        device = await session.get(Device, device_id)
        bunker = await session.get(Bunker, device.bunker_id)

        # Check emergency mode
        if await self._check_emergency_mode(bunker.id, session):
            return ShutdownDecision(
                shutdown_allowed=False,
                reset_countdown=False,
                reason="emergency_on"
            )

        # Check time window overrides
        if await self._check_time_overrides(bunker.id, session):
            return ShutdownDecision(
                shutdown_allowed=False,
                reset_countdown=False,
                reason="time_window_override"
            )

        # Check wind conditions
        weather = weather_service.get_current_weather()
        threshold = bunker.wind_threshold_mph or await self._get_global_threshold(session)

        if weather.wind_speed_mph >= threshold:
            logger.info(f"Shutdown allowed: wind {weather.wind_speed_mph:.1f} mph >= {threshold} mph")
            return ShutdownDecision(
                shutdown_allowed=True,
                reset_countdown=True,
                reason="wind_conditions_favorable"
            )

        # Default: fail-safe
        return ShutdownDecision(
            shutdown_allowed=False,
            reset_countdown=False,
            reason="default_safe"
        )
