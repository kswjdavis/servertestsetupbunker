# Story 2.5: Control Logic Engine (Backend)

## Status
Draft

## Story
**As a** backend server,
**I want** centralized control logic that determines when fans can shut down based on wind conditions,
**so that** the server makes consistent, safe shutdown decisions for all devices (FR2).

## Acceptance Criteria

1. ControlLogicEngine class with should_shutdown_fans() method
2. Decision based on: wind speed >= threshold AND no active overrides AND no emergency mode
3. Returns ShutdownDecision object with: shutdown_allowed (bool), reset_countdown (bool), reason (string)
4. Wind threshold compared against wind_speed_mph from WeatherService
5. Emergency mode check per-bunker and global
6. Time window override check (active NOW for this bunker)
7. Default decision is shutdown_allowed=False (fail-safe)
8. All logic unit-tested with pytest
9. Decision logged at INFO level for audit trail
10. Integrated into POST /api/v1/control/status endpoint

                reset_countdown=False,
                reason="emergency_on"

        if await self._check_time_overrides(bunker.id, session):
            return ShutdownDecision(

                reset_countdown=False,
                reason="time_window_override"
