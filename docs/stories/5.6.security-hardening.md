# Story 5.6: Security Hardening and Review

## Status
Draft

## Story
**As a** security engineer,
**I want** security review and hardening of the system,
**so that** production deployment is secure against common vulnerabilities.

## Acceptance Criteria

1. All passwords stored with bcrypt hashing
2. JWT tokens use strong secret keys (minimum 32 bytes)
3. HTTPS enforced (HTTP redirects to HTTPS)
4. CORS properly configured (no wildcards in production)
5. SQL injection prevented (using ORM parameterized queries)
6. XSS prevention (React escapes by default, verify)
7. CSRF protection not needed (token-based auth)
8. Rate limiting on login endpoint (prevent brute force)
9. No sensitive data in logs (tokens, passwords)
10. Security checklist completed and documented

### Security Checklist

**Password Security (AC1):**
```python
# server/app/core/security.py - VERIFY
from passlib.context import CryptContext

pwd_context = CryptContext(schemes=["bcrypt"], deprecated="auto")
# Bcrypt cost factor = 12 (default) - VERIFIED
```

**JWT Security (AC2):**
```python
# server/app/config.py - UPDATE
import secrets

SECRET_KEY = os.getenv("SECRET_KEY")  # Min 32 chars
if len(SECRET_KEY) < 32:
    raise ValueError("SECRET_KEY must be at least 32 characters")

JWT_ALGORITHM = "HS256"
ACCESS_TOKEN_EXPIRE_HOURS = 24
```

**HTTPS Enforcement (AC3):**
```nginx
# config/nginx.conf - VERIFY
server {
    listen 80;
    return 301 https://$server_name$request_uri;  # Force HTTPS
}
```

**CORS Configuration (AC4):**
```python
# server/app/main.py - UPDATE
from fastapi.middleware.cors import CORSMiddleware

app.add_middleware(
    CORSMiddleware,
    allow_origins=["https://bunkercolab.example.com"],  # No wildcards!
    allow_credentials=True,
    allow_methods=["GET", "POST", "PUT", "DELETE"],
    allow_headers=["*"],
)
```

**SQL Injection Prevention (AC5):**
```python
# server/app/repositories/bunker_repository.py - VERIFY
# Using SQLAlchemy ORM parameterized queries - SAFE
result = await self.db.execute(
    select(Bunker).where(Bunker.id == bunker_id)  # Parameterized
)
# NEVER use raw SQL with f-strings!
```

**XSS Prevention (AC6):**
```typescript
// React auto-escapes by default - VERIFY no dangerouslySetInnerHTML usage
// web/src/ - AUDIT
grep -r "dangerouslySetInnerHTML" src/  # Should return nothing
```

**Rate Limiting (AC8):**
```python
# server/app/api/auth.py - ADD
from slowapi import Limiter
from slowapi.util import get_remote_address

limiter = Limiter(key_func=get_remote_address)

@router.post("/login")
@limiter.limit("5/minute")  # Max 5 login attempts per minute
async def login(credentials: UserCredentials):
    # ... existing login logic
```

**Logging Audit (AC9):**
```python
# server/app/ - AUDIT all logging
# BAD: ESP_LOGI(TAG, "Token: %s", auth_token);  # REMOVE
# GOOD: ESP_LOGI(TAG, "Device authenticated");  # OK

# Use grep to find sensitive data in logs
grep -r "password\|token\|secret" server/app/ | grep -i log
```
