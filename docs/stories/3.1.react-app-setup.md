# Story 3.1: React App Setup and Routing

## Status
Ready for Dev

## Story
**As a** frontend developer (Will),
**I want** React app with routing, authentication context, and basic layout structure,
**so that** I have a foundation to build all UI features.

## Acceptance Criteria

1. React Router v6 configured with protected routes
2. AuthContext provides login, logout, currentUser, isAuthenticated
3. App layout with header, main content area, and navigation
4. Routes defined: /login, /dashboard, /bunkers/:id, /devices, /settings
5. Protected routes redirect to /login if not authenticated
6. Axios client configured with base URL and auth interceptor
7. Tailwind CSS configured and working
8. TypeScript interfaces for API responses
9. Error boundary for graceful error handling
10. App runs without console errors

## Dev Notes

```typescript
// App.tsx
import { BrowserRouter, Routes, Route, Navigate } from 'react-router-dom';
import { AuthProvider } from './context/AuthContext';
import ProtectedRoute from './components/ProtectedRoute';

function App() {
  return (
    <AuthProvider>
      <BrowserRouter>
        <Routes>
          <Route path="/login" element={<LoginPage />} />
          <Route element={<ProtectedRoute />}>
            <Route path="/dashboard" element={<Dashboard />} />
            <Route path="/bunkers/:id" element={<BunkerDetail />} />
            <Route path="/devices" element={<DeviceList />} />
            <Route path="/settings" element={<Settings />} />
          </Route>
          <Route path="/" element={<Navigate to="/dashboard" replace />} />
        </Routes>
      </BrowserRouter>
    </AuthProvider>
  );
}
```
