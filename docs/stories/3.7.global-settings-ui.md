# Story 3.7: Global Configuration Settings UI

## Status
Draft

## Story
**As a** system administrator,
**I want** settings page to configure global system parameters,
**so that** I can adjust wind thresholds, energy costs, and weather station (FR33, FR34, FR35).

## Acceptance Criteria

1. Settings page with form for GlobalConfig
2. Fields: Weather Station ID, Wind Threshold (mph), Electricity Cost ($/kWh), Fan Power (watts)
3. Fetch current config from GET /api/v1/config
4. Save updates via PUT /api/v1/config
5. Form validation (positive numbers, valid station ID format)
6. Success/error messages after save
7. Reset button to revert unsaved changes
8. Help text explaining each setting
9. Responsive form layout
10. Loading state while fetching/saving

### Component Pattern

Follow standard React + TypeScript component pattern:
[Source: architecture.md#Frontend Architecture - Component Template Example]

```typescript
// pages/SettingsPage.tsx
import React, { useState, useEffect } from 'react';
import * as configService from '@/services/config.service';

export const SettingsPage: React.FC = () => {
  const [config, setConfig] = useState<GlobalConfig | null>(null);
  const [formData, setFormData] = useState<GlobalConfig | null>(null);
  const [loading, setLoading] = useState(true);
  const [saving, setSaving] = useState(false);
  const [errors, setErrors] = useState<Record<string, string>>({});

  useEffect(() => {
    fetchConfig();
  }, []);

  const fetchConfig = async () => {
    try {
      const data = await configService.getConfig();
      setConfig(data);
      setFormData(data);
      setLoading(false);
    } catch (error) {
      toast.error('Failed to load configuration');
    }
  };

  const handleSave = async () => {
    if (!validateForm()) return;

    setSaving(true);
    try {
      const updated = await configService.updateConfig(formData!);
      setConfig(updated);
      toast.success('Configuration saved successfully');
    } catch (error) {
      toast.error('Failed to save configuration');
    } finally {
      setSaving(false);
    }
  };

  const handleReset = () => {
    setFormData(config);
    setErrors({});
  };

  return (
    <div className="container mx-auto p-6 max-w-2xl">
      <h1 className="text-2xl font-bold mb-6">Global Settings</h1>
      {/* Form fields */}
    </div>
  );
};
```

### Form Validation

Implement validation for all fields:

```typescript
// utils/configValidation.ts
export function validateGlobalConfig(config: GlobalConfig): Record<string, string> {
  const errors: Record<string, string> = {};

  // Wind threshold must be positive
  if (config.default_wind_threshold_mph <= 0) {
    errors.default_wind_threshold_mph = 'Wind threshold must be greater than 0';
  }
  if (config.default_wind_threshold_mph > 100) {
    errors.default_wind_threshold_mph = 'Wind threshold seems unreasonably high';
  }

  // Electricity cost must be positive
  if (config.default_electricity_cost_kwh <= 0) {
    errors.default_electricity_cost_kwh = 'Electricity cost must be greater than 0';
  }

  // Fan power must be positive
  if (config.default_fan_power_watts <= 0) {
    errors.default_fan_power_watts = 'Fan power must be greater than 0';
  }

  // Weather station ID format (4-letter ICAO code)
  if (!/^[A-Z]{4}$/.test(config.weather_station_id)) {
    errors.weather_station_id = 'Station ID must be 4 uppercase letters (e.g., KOKC)';
  }

  return errors;
}
```

### Form Field Component

Reusable form field with label, input, validation, and help text:

```typescript
// components/settings/FormField.tsx
interface FormFieldProps {
  label: string;
  name: string;
  type: 'text' | 'number';
  value: string | number;
  onChange: (value: string | number) => void;
  error?: string;
  helpText?: string;
  unit?: string;
}

export const FormField: React.FC<FormFieldProps> = ({
  label,
  name,
  type,
  value,
  onChange,
  error,
  helpText,
  unit
}) => {
  return (
    <div className="mb-4">
      <label className="block text-sm font-medium text-gray-700 mb-1">
        {label}
      </label>
      <div className="flex items-center gap-2">
        <input
          type={type}
          name={name}
          value={value}
          onChange={(e) => onChange(type === 'number' ? parseFloat(e.target.value) : e.target.value)}
          className={`flex-1 px-3 py-2 border rounded-md ${error ? 'border-red-500' : 'border-gray-300'}`}
        />
        {unit && <span className="text-gray-500">{unit}</span>}
      </div>
      {helpText && <p className="text-xs text-gray-500 mt-1">{helpText}</p>}
      {error && <p className="text-xs text-red-500 mt-1">{error}</p>}
    </div>
  );
};
```

### Service Layer Implementation

```typescript
// services/config.service.ts
import api from './api';
import { GlobalConfig } from '@/types';

export async function getConfig(): Promise<GlobalConfig> {
  const response = await api.get<GlobalConfig>('/config');
  return response.data;
}

export async function updateConfig(config: GlobalConfig): Promise<GlobalConfig> {
  const response = await api.put<GlobalConfig>('/config', config);
  return response.data;
}
```
