# Story 2.2: ESP32 Relay Controller (Fail-Safe Design)

## Status
Done

## Story
**As an** ESP32 device,
**I want** GPIO-based relay control with normally-closed fail-safe design,
**so that** fans default to ON in any electrical or software failure.

## Acceptance Criteria

1. Relay connected to GPIO pin (configurable via menuconfig)
2. Relay is normally-closed type (fans ON when relay de-energized) (FR21)
3. GPIO initialized LOW on boot (relay closed = fans ON)
4. `relay_set_on()` sets GPIO LOW (energize relay, fans ON)
5. `relay_set_off()` sets GPIO HIGH (de-energize relay, fans OFF)
6. `relay_force_on()` sets GPIO LOW and locks state (cannot be changed)
7. Force-on state persists until device reboot
8. Relay state changes logged via ESP_LOG
9. Relay state is readable by status reporting task
10. Hardware watchdog ensures relay returns to ON if firmware hangs

```c
#endif
```

```c
// relay_controller.c
#include "relay_controller.h"
#include "driver/gpio.h"
#include "esp_log.h"

static const char *TAG = "relay";

#define RELAY_GPIO CONFIG_RELAY_GPIO_PIN  // From menuconfig

typedef enum {
    RELAY_STATE_ON,   // GPIO LOW = relay closed = fans ON
    RELAY_STATE_OFF   // GPIO HIGH = relay open = fans OFF
} relay_state_t;

static relay_state_t current_state = RELAY_STATE_ON;
static bool force_on_locked = false;

void relay_controller_init(void) {
    // Configure GPIO as output
    gpio_config_t io_conf = {
        .pin_bit_mask = (1ULL << RELAY_GPIO),
        .mode = GPIO_MODE_OUTPUT,
        .pull_up_en = GPIO_PULLUP_DISABLE,
        .pull_down_en = GPIO_PULLDOWN_DISABLE,
        .intr_type = GPIO_INTR_DISABLE
    };
    gpio_config(&io_conf);

    // FAIL-SAFE: Initialize to ON (fans running)
    gpio_set_level(RELAY_GPIO, 0);  // LOW = normally-closed relay closed = fans ON
    current_state = RELAY_STATE_ON;

    ESP_LOGI(TAG, "Relay controller initialized (GPIO %d)", RELAY_GPIO);
    ESP_LOGI(TAG, "✓ FAIL-SAFE: Fans ON by default (normally-closed relay)");
}

void relay_set_on(void) {
    if (force_on_locked) {
        return;  // Already locked ON
    }

    gpio_set_level(RELAY_GPIO, 0);  // LOW = fans ON
    current_state = RELAY_STATE_ON;
    ESP_LOGI(TAG, "Relay: ON (fans running)");
}

void relay_set_off(void) {
    if (force_on_locked) {
        ESP_LOGW(TAG, "Cannot turn relay OFF - locked in fail-safe mode");
        return;
    }

    gpio_set_level(RELAY_GPIO, 1);  // HIGH = fans OFF
    current_state = RELAY_STATE_OFF;
    ESP_LOGI(TAG, "Relay: OFF (fans stopped - energy saving)");
}

void relay_force_on(void) {
    gpio_set_level(RELAY_GPIO, 0);  // LOW = fans ON
    current_state = RELAY_STATE_ON;
    force_on_locked = true;

    ESP_LOGE(TAG, "⚠ RELAY FORCED ON - FAIL-SAFE MODE ACTIVE");
    ESP_LOGE(TAG, "⚠ Relay locked until device reboot");
}

const char* relay_get_state(void) {
    return (current_state == RELAY_STATE_ON) ? "ON" : "OFF";
}

bool relay_is_locked(void) {
    return force_on_locked;
}
```

### Fail-Safe Design Verification

**Failure Scenarios:**
1. ❌ Power loss → Relay de-energizes → Normally-closed contacts close → Fans ON ✅
2. ❌ ESP32 crash → Watchdog reboots → GPIO initializes LOW → Fans ON ✅
3. ❌ WiFi loss → Dead-man timer expires → relay_force_on() → Fans ON ✅
4. ❌ Server down → Dead-man timer expires → relay_force_on() → Fans ON ✅

**All failure modes result in fans ON = Safe state**
