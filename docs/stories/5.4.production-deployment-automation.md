### Deployment Scripts

**deploy-server.sh (AC1):**
```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"
SERVER_DIR="${PROJECT_ROOT}/server"
VENV_DIR="${SERVER_DIR}/venv"
ENV_FILE="${SERVER_DIR}/.env.production"

usage() {
  cat <<'USAGE'
Deploy the FastAPI backend.

Usage: ./deploy-server.sh [--skip-git]
USAGE
}

# optional --skip-git flag handled above ...
ensure_command python3
ensure_command git
ensure_command sudo

# create/upgrade venv, install requirements, load env, run Alembic
"${VENV_DIR}/bin/python" -m pip install --upgrade pip
"${VENV_DIR}/bin/pip" install -r requirements.txt
source "${ENV_FILE}"
"${VENV_DIR}/bin/alembic" upgrade head

# render config/bunkercolab.service into /etc/systemd/system/bunkercolab.service
sed \
  -e "s#__PROJECT_ROOT__#${PROJECT_ROOT}#g" \
  -e "s#__DEPLOY_USER__#$(whoami)#g" \
  "${SYSTEMD_TEMPLATE}" | sudo tee "/etc/systemd/system/${SERVICE_NAME}.service" >/dev/null
sudo systemctl daemon-reload
sudo systemctl restart "${SERVICE_NAME}"
```

**build-web.sh (AC2):**
```bash
#!/usr/bin/env bash
set -euo pipefail

SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
PROJECT_ROOT="$(cd "${SCRIPT_DIR}/.." && pwd)"
WEB_DIR="${PROJECT_ROOT}/web"
NGINX_ROOT="${WEB_DEPLOY_ROOT:-/var/www/bunkercolab}"

usage() {
  cat <<'USAGE'
Build the React frontend and deploy assets to nginx.

Usage: ./build-web.sh [--skip-install]
USAGE
}

# install Node.js (Nodesource) if npm missing, npm ci/install
npm run build
sudo mkdir -p "${NGINX_ROOT}"
sudo rm -rf "${NGINX_ROOT:?}/"*
sudo cp -r dist/. "${NGINX_ROOT}/"
sudo chown -R www-data:www-data "${NGINX_ROOT}"
```

**setup-db.sh (AC3):**
```bash
#!/usr/bin/env bash
set -euo pipefail

DB_NAME="${DB_NAME:-bunkercolab}"
DB_USER="${DB_USER:-bunkercolab_user}"
DB_PASSWORD="${DB_PASSWORD:-}"

usage() {
  cat <<'USAGE'
Initialize PostgreSQL database and role.

Usage: sudo ./setup-db.sh [--db-name NAME] [--db-user USER] [--db-password PASS]
USAGE
}

# optional apt install, validates identifiers, prompts for password
sudo -u postgres psql -c "CREATE USER ${DB_USER} WITH PASSWORD '***';"
sudo -u postgres psql -c "CREATE DATABASE ${DB_NAME} OWNER ${DB_USER};"
sudo -u postgres psql -c "GRANT ALL PRIVILEGES ON DATABASE ${DB_NAME} TO ${DB_USER};"
```

**rollback.sh (AC9):**
```bash
#!/usr/bin/env bash
set -euo pipefail

usage() {
  cat <<'USAGE'
Rollback repository to previous commit.

Usage: ./rollback.sh <git-ref> [--no-restart]
USAGE
}

git -C "${PROJECT_ROOT}" fetch --all --prune
git -C "${PROJECT_ROOT}" reset --hard "${TARGET_REF}"
sudo systemctl restart "${SERVICE_NAME}"
```

**bunkercolab.service (AC7):**
```ini
[Unit]
Description=Bunkercolab FastAPI Backend
After=network.target postgresql.service
Wants=postgresql.service

[Service]
Type=simple
User=__DEPLOY_USER__
Group=__DEPLOY_USER__
WorkingDirectory=__PROJECT_ROOT__/server
Environment="PATH=__PROJECT_ROOT__/server/venv/bin"
Environment="PYTHONPATH=__PROJECT_ROOT__/server"
EnvironmentFile=__PROJECT_ROOT__/server/.env.production
ExecStart=__PROJECT_ROOT__/server/venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8000 --workers 2
Restart=always
RestartSec=5
TimeoutStopSec=30

[Install]
WantedBy=multi-user.target
```

    root /var/www/bunkercolab;
    index index.html;

    location / {
        try_files $uri $uri/ /index.html;

        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;

## Production Deployment

### 1. Prerequisites
- Ubuntu 24.04 LTS droplet (2 GB RAM)

```bash
sudo ./scripts/setup-droplet.sh

```bash
cd ~/Bunkercolab/server
cp .env.production.example .env.production
nano .env.production
chmod 600 .env.production

### 4. Systemd + Backend Deploy
```bash
cd ~/Bunkercolab/scripts
./deploy-server.sh
sudo systemctl status bunkercolab
```

### 5. Nginx + TLS
```bash
sudo cp ~/Bunkercolab/config/nginx.conf /etc/nginx/sites-available/bunkercolab
sudo nginx -t && sudo systemctl reload nginx
sudo certbot --nginx -d bunkercolab.example.com
```

```bash
./build-web.sh
```

### 7. Rollback Procedure
```bash
./rollback.sh <commit-or-tag>
```

- React SPA serves over HTTPS without warnings
- Systemd service is `active (running)`
- PostgreSQL schema present

### Refactoring Performed

**1. File**: scripts/setup-db.sh (lines 132-142)
   - **Change**: Removed password from summary output
   - **Why**: Security - passwords should never be displayed in terminal output or logs
   - **How**: Replaced `${DB_PASSWORD}` with `<PASSWORD>` placeholder and added security notice

**2. File**: config/nginx.conf (lines 28-35)
   - **Change**: Added security headers (HSTS, X-Frame-Options, X-Content-Type-Options, X-XSS-Protection, Referrer-Policy) and client_max_body_size limit
   - **Why**: Protect against common web vulnerabilities (clickjacking, MIME sniffing, XSS) and enforce HTTPS usage
   - **How**: Added `add_header` directives with `always` flag to ensure headers on all responses

**3. File**: config/bunkercolab.service (lines 19-27)
   - **Change**: Added systemd security hardening directives
   - **Why**: Reduce attack surface by restricting service capabilities
   - **How**: Added PrivateTmp, ProtectSystem=strict, ProtectHome, ReadWritePaths, NoNewPrivileges, and kernel protection flags

**4. File**: scripts/build-web.sh (lines 104-113)
   - **Change**: Replaced `rm -rf` with path validation + `find -delete`
   - **Why**: Prevent catastrophic deletion if NGINX_ROOT variable is misconfigured
   - **How**: Added regex validation requiring paths under /var/www/ or /opt/, then use `find -mindepth 1 -delete` instead of glob expansion

**5. File**: scripts/rollback.sh (lines 65-79, 86)
   - **Change**: Added git ref validation before prompting user, show resolved commit hash
   - **Why**: Prevent rollback failures after user confirmation, provide clear visibility of target
   - **How**: Validate ref exists with `git rev-parse --verify`, show available tags on failure, use resolved SHA for reset
