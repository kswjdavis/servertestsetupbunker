### Deployment Scripts

**deploy-server.sh (AC1):**
```bash
#!/bin/bash
set -e  # Exit on error

echo "Deploying FastAPI backend..."
cd /home/bunkercolab/Bunkercolab/server

# Pull latest code
git pull origin main

# Activate virtual environment
source venv/bin/activate

# Install dependencies
pip install -r requirements.txt

# Run database migrations
alembic upgrade head

# Restart backend service
sudo systemctl restart bunkercolab

echo "Backend deployed successfully!"
```

**build-web.sh (AC2):**
```bash
#!/bin/bash
set -e

echo "Building React frontend..."
cd /home/bunkercolab/Bunkercolab/web

# Install dependencies
npm install

# Build production bundle
npm run build

# Copy to Nginx directory
sudo rm -rf /var/www/bunkercolab/*
sudo cp -r dist/* /var/www/bunkercolab/
sudo chown -R www-data:www-data /var/www/bunkercolab

echo "Frontend built and deployed!"
```

**setup-db.sh (AC3):**
```bash
#!/bin/bash
set -e

echo "Setting up PostgreSQL..."

# Install PostgreSQL
sudo apt install -y postgresql postgresql-contrib

# Create database and user
sudo -u postgres psql <<EOF
CREATE DATABASE bunkercolab;
CREATE USER bunkercolab_user WITH PASSWORD '${DB_PASSWORD}';
GRANT ALL PRIVILEGES ON DATABASE bunkercolab TO bunkercolab_user;
\\q
EOF

echo "Database setup complete!"
```

### Configuration Files

**bunkercolab.service (AC7):**
```ini
[Unit]
Description=Bunker Colab FastAPI Application
After=network.target postgresql.service

[Service]
User=bunkercolab
Group=bunkercolab
WorkingDirectory=/home/bunkercolab/Bunkercolab/server
Environment="PATH=/home/bunkercolab/Bunkercolab/server/venv/bin"
EnvironmentFile=/home/bunkercolab/Bunkercolab/server/.env.production
ExecStart=/home/bunkercolab/Bunkercolab/server/venv/bin/uvicorn app.main:app --host 0.0.0.0 --port 8000 --workers 2
Restart=always
RestartSec=5

[Install]
WantedBy=multi-user.target
```

**nginx.conf (AC5):**
```nginx
server {
    listen 80;
    server_name bunkercolab.example.com;
    return 301 https://$server_name$request_uri;
}

server {
    listen 443 ssl http2;
    server_name bunkercolab.example.com;

    ssl_certificate /etc/letsencrypt/live/bunkercolab.example.com/fullchain.pem;
    ssl_certificate_key /etc/letsencrypt/live/bunkercolab.example.com/privkey.pem;

    location / {
        root /var/www/bunkercolab;
        try_files $uri $uri/ /index.html;
    }

    location /api/ {
        proxy_pass http://127.0.0.1:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
```

### Deployment Guide (AC8)

**docs/deployment-guide.md excerpt:**
```markdown
## Production Deployment

### Prerequisites
- DigitalOcean droplet (Ubuntu 22.04, 2GB RAM)
- Domain name pointed to droplet IP
- SSH access

### Initial Setup
1. Clone repository: `git clone <repo-url>`
2. Run database setup: `bash scripts/setup-db.sh`
3. Configure environment: `cp server/.env.production.example server/.env.production`
4. Edit `.env.production` with production values

### Deploy Backend
```bash
bash scripts/deploy-server.sh
```

### Deploy Frontend
```bash
bash scripts/build-web.sh
```

### Setup SSL (AC6)
```bash
sudo certbot --nginx -d bunkercolab.example.com
```

### Rollback (AC9)
```bash
bash scripts/rollback.sh <previous-git-commit-hash>
```
```
