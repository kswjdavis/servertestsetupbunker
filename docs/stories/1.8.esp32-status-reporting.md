# Story 1.8: ESP32 Status Reporting to Server

## Status
Ready for Review

## Story
**As an** ESP32 device,
**I want** to report my status to the server every 60 seconds,
**so that** the server knows I'm online and can send shutdown commands.

## Acceptance Criteria

1. ESP32 sends POST /api/v1/control/status every 60 seconds (FR23)
2. JSON payload includes: relay_state, uptime_seconds, wifi_rssi, countdown_timer_remaining, firmware_version
3. Server endpoint accepts device status and updates database
4. Server response includes: shutdown_allowed, reset_countdown, server_time
5. ESP32 parses server response and logs decision
6. Status reporting task runs as FreeRTOS periodic task
7. Task continues running even if individual requests fail
8. Uptime calculated from esp_timer_get_time()
9. WiFi RSSI obtained from esp_wifi_sta_get_rssi()
10. First status report sent immediately after WiFi connection

### ESP32 Status Reporting Task

```c
#include "cJSON.h"
#include "esp_wifi.h"
#include "esp_timer.h"

#define STATUS_REPORT_INTERVAL_MS 60000  // 60 seconds

void status_reporting_task(void *pvParameters) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    const TickType_t xPeriod = pdMS_TO_TICKS(STATUS_REPORT_INTERVAL_MS);

    while (1) {
        if (wifi_is_connected()) {
            send_status_to_server();
        } else {
            ESP_LOGW(TAG, "Skipping status report - WiFi not connected");
        }

        vTaskDelayUntil(&xLastWakeTime, xPeriod);
    }
}

void send_status_to_server(void) {
    // Build JSON payload
    cJSON *root = cJSON_CreateObject();
    cJSON_AddStringToObject(root, "relay_state", get_relay_state());
    cJSON_AddNumberToObject(root, "uptime_seconds", get_uptime_seconds());
    cJSON_AddNumberToObject(root, "wifi_rssi", get_wifi_rssi());
    cJSON_AddNumberToObject(root, "countdown_timer_remaining", get_countdown_remaining());
    cJSON_AddStringToObject(root, "firmware_version", FIRMWARE_VERSION);

    char *json_payload = cJSON_PrintUnformatted(root);
    cJSON_Delete(root);

    // Send HTTP POST
    esp_err_t err = http_post_status(json_payload);

    if (err == ESP_OK) {
        ESP_LOGI(TAG, "Status report sent successfully");
        parse_server_response();
    } else {
        ESP_LOGW(TAG, "Failed to send status report");
    }

    free(json_payload);
}

uint32_t get_uptime_seconds(void) {
    return (uint32_t)(esp_timer_get_time() / 1000000);
}

int8_t get_wifi_rssi(void) {
    wifi_ap_record_t ap_info;
    esp_wifi_sta_get_ap_info(&ap_info);
    return ap_info.rssi;
}
```

### Server Response Parsing

```c
typedef struct {
    bool shutdown_allowed;
    bool reset_countdown;
    char server_time[32];
} server_decision_t;

server_decision_t parse_server_response(const char *response_buffer) {
    server_decision_t decision = {false, false, ""};

    cJSON *json = cJSON_Parse(response_buffer);
    if (json == NULL) {
        ESP_LOGE(TAG, "Failed to parse server response");
        return decision;
    }

    cJSON *shutdown = cJSON_GetObjectItem(json, "shutdown_allowed");
    if (cJSON_IsBool(shutdown)) {
        decision.shutdown_allowed = cJSON_IsTrue(shutdown);
    }

    cJSON *reset = cJSON_GetObjectItem(json, "reset_countdown");
    if (cJSON_IsBool(reset)) {
        decision.reset_countdown = cJSON_IsTrue(reset);
    }

    cJSON *time = cJSON_GetObjectItem(json, "server_time");
    if (cJSON_IsString(time)) {
        strncpy(decision.server_time, time->valuestring, sizeof(decision.server_time) - 1);
    }

    ESP_LOGI(TAG, "Server decision: shutdown_allowed=%d, reset_countdown=%d",
             decision.shutdown_allowed, decision.reset_countdown);

    cJSON_Delete(json);
    return decision;
}
```

### Server-Side Endpoint (Backend)

```python
from fastapi import APIRouter, Depends, HTTPException
from app.schemas.device import DeviceStatusRequest, DeviceStatusResponse
from app.core.security import get_current_device

router = APIRouter(prefix="/api/v1/control", tags=["control"])

@router.post("/status", response_model=DeviceStatusResponse)
async def device_status_report(
    status: DeviceStatusRequest,
    device: Device = Depends(get_current_device),
    session: AsyncSession = Depends(get_db)
):
    """
    ESP32 devices call this endpoint every 60 seconds to report status
    and receive shutdown decision from server.
    """
    # Update device last_seen
    device.last_seen = datetime.utcnow()

    # Upsert device status
    device_status = DeviceStatus(
        device_id=device.id,
        relay_state=status.relay_state,
        uptime_seconds=status.uptime_seconds,
        wifi_rssi=status.wifi_rssi,
        countdown_timer_remaining=status.countdown_timer_remaining,
        reported_at=datetime.utcnow(),
        server_received_at=datetime.utcnow()
    )

    await session.merge(device_status)
    await session.commit()

    # Get shutdown decision from control logic engine
    decision = control_logic_engine.should_shutdown_fans(device.id)

    return DeviceStatusResponse(
        shutdown_allowed=decision.shutdown_allowed,
        reset_countdown=decision.reset_countdown,
        shutdown_reason=decision.reason,
        server_time=datetime.utcnow().isoformat()
    )
```

### Refactoring Performed

#### Critical Bug Fix

- **File**: `server/app/api/v1/endpoints/control.py:39`
  - **Change**: Added `await session.commit()` after updating device.last_seen and device.firmware_version
  - **Why**: Device model updates were being made but never persisted to the database, violating the "Database Transactions" coding standard. This would cause last_seen timestamps and firmware versions to never update in production.
  - **How**: Added explicit commit after device attribute updates, before the repository upsert operation. This ensures device heartbeat and firmware tracking work correctly.
  - **Impact**: CRITICAL - Without this fix, device online/offline detection (is_online property based on last_seen) would be broken, and firmware version tracking would fail.

**Test Verification:** All 8 existing integration tests pass after the fix, confirming backward compatibility.
