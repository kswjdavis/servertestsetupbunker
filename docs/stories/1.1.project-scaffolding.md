# Story 1.1: Project Scaffolding and Monorepo Setup

## Status
Draft

## Story
**As a** development team,
**I want** a fully initialized monorepo with all three components (firmware, server, web) scaffolded with proper tooling,
**so that** Jeff and Will can begin parallel development immediately with consistent environments.

## Acceptance Criteria

1. Monorepo structure created with `/firmware`, `/server`, `/web`, `/docs`, `/scripts` directories
2. Backend FastAPI project initialized with proper package structure and configuration files
3. Frontend React+Vite+TypeScript project initialized with Tailwind CSS
4. ESP32 firmware project created using `idf.py create-project`
5. PostgreSQL database created locally with initial connection verified
6. All dependency installation commands documented and verified working
7. .env.example files created for backend and frontend
8. .gitignore configured appropriately for all three components
9. README.md created with quick-start instructions for local setup
10. All developers can run `setup` commands and get working dev environments

## Tasks / Subtasks

- [ ] Create monorepo directory structure (AC: 1)
  - [ ] Create firmware/, server/, web/, docs/, scripts/ directories
  - [ ] Initialize git repository with initial commit

- [ ] Setup FastAPI backend project (AC: 2)

  - [ ] Run `idf.py create-project firmware`

  - [ ] Create firmware/main/CMakeLists.txt
