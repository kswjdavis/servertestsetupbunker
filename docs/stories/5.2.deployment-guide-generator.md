# Story 5.2: Printable Deployment Guide Generator

## Status
Ready for Dev

## Story
**As a** system administrator,
**I want** printable deployment guide showing bunker layouts and device mappings,
**so that** field technicians can deploy ESP32 devices correctly (FR40).

## Acceptance Criteria

1. "Generate Deployment Guide" button on bunker detail page
2. Generated PDF or print-friendly HTML page
3. Shows: Bunker name, location, fan layout diagram
4. Lists each device: Position, LED flash pattern, MAC address, Auth token (redacted)
5. QR code for device provisioning page (optional)
6. Clear instructions for ESP32 installation
7. Print layout optimized for standard 8.5x11" paper
8. CSS print styles hide navigation/buttons
9. Can generate guide for single bunker or all bunkers
10. Responsive design for screen preview

## Dev Notes

### Overview
This story implements a printable deployment guide generator that creates field-ready documentation for ESP32 device installation. The guide displays bunker layouts, device mappings, LED flash patterns, and installation instructions in a print-optimized format. Reference **docs/architecture.md#Frontend Architecture**.

### Implementation

**DeploymentGuide.tsx (AC1, AC2, AC3, AC4):**
```typescript
import React from 'react';
import { Bunker, Device } from '@/types';

interface DeploymentGuideProps {
  bunkers: Bunker[];
  devices: Record<string, Device[]>;  // keyed by bunker_id
}

export const DeploymentGuide: React.FC<DeploymentGuideProps> = ({ bunkers, devices }) => {
  return (
    <div className="deployment-guide">
      {bunkers.map((bunker) => (
        <div key={bunker.id} className="bunker-section page-break">
          {/* AC3: Header */}
          <h1>{bunker.name}</h1>
          <p>Location: {bunker.latitude.toFixed(4)}, {bunker.longitude.toFixed(4)}</p>
          <p>Orientation: {bunker.orientation_degrees}°</p>

          {/* AC3: Fan layout diagram */}
          <BunkerLayoutDiagram
            fanCount={bunker.fan_count}
            orientation={bunker.orientation_degrees}
          />

          {/* AC4: Device table */}
          <table className="device-table">
            <thead>
              <tr>
                <th>Position</th>
                <th>LED Flash</th>
                <th>MAC Address</th>
                <th>Auth Token</th>
              </tr>
            </thead>
            <tbody>
              {devices[bunker.id]?.map((device) => (
                <tr key={device.id}>
                  <td>Fan {device.fan_position}</td>
                  <td>{device.led_flash_sequence} blinks</td>
                  <td><code>{device.mac_address}</code></td>
                  <td><code>{device.id.substring(0, 8)}...</code></td>
                </tr>
              ))}
            </tbody>
          </table>

          {/* AC6: Installation instructions */}
          <div className="instructions">
            <h3>Installation Steps:</h3>
            <ol>
              <li>Power on ESP32 device</li>
              <li>Count LED blinks to identify device</li>
              <li>Install device at fan position matching LED pattern</li>
              <li>Connect to fan relay control</li>
              <li>Verify device appears online in Web UI</li>
            </ol>
          </div>
        </div>
      ))}
    </div>
  );
};
```

**BunkerLayoutDiagram.tsx (AC3):**
```typescript
import React from 'react';

interface BunkerLayoutDiagramProps {
  fanCount: number;
  orientation: number;
}

export const BunkerLayoutDiagram: React.FC<BunkerLayoutDiagramProps> = ({ fanCount, orientation }) => {
  // Simple grid layout showing fan positions
  const fans = Array.from({ length: fanCount }, (_, i) => i + 1);

  return (
    <div className="bunker-diagram">
      <svg width="400" height="200" viewBox="0 0 400 200">
        {/* Bunker outline */}
        <rect x="50" y="50" width="300" height="100" fill="none" stroke="#000" strokeWidth="2" />

        {/* Orientation arrow */}
        <line x1="200" y1="20" x2="200" y2="40" stroke="#000" strokeWidth="2" />
        <polygon points="200,15 195,25 205,25" fill="#000" />
        <text x="210" y="30" fontSize="12">N ({orientation}°)</text>

        {/* Fan positions */}
        {fans.map((pos) => {
          const x = 70 + ((pos - 1) % 10) * 28;
          const y = 70 + Math.floor((pos - 1) / 10) * 30;
          return (
            <g key={pos}>
              <circle cx={x} cy={y} r="10" fill="#4A90E2" stroke="#000" strokeWidth="1" />
              <text x={x} y={y + 5} textAnchor="middle" fontSize="10" fill="#fff">{pos}</text>
            </g>
          );
        })}
      </svg>
    </div>
  );
};
```
