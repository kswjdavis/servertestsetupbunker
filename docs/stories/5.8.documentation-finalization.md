uvicorn app.main:app --reload

### Operator Manual (AC5)
```markdown
# Operator Manual

## Logging In
1. Navigate to https://bunkercolab.example.com
2. Enter username and password
3. Click "Login"

## Managing Bunkers
### Create Bunker
1. Click "Add Bunker"
2. Fill in: Name, Location (lat/lng), Orientation, Fan count
3. Click "Save"

### Provisioning Devices
1. Navigate to bunker detail page
2. Click "Add Device"
3. Enter MAC address and fan position
4. Save auth token (shown once!)
5. Flash ESP32 with firmware
6. Configure WiFi and auth token via serial

## Monitoring
- Dashboard shows all bunkers with status indicators
- Green = all fans online
- Yellow = some fans offline
- Red = critical (>30% offline)

## Energy Savings
- View daily/weekly/monthly energy saved
- Export reports as CSV

## Troubleshooting
See [Troubleshooting Guide](troubleshooting-guide.md)
```

### Troubleshooting Guide (AC7)
```markdown
# Troubleshooting Guide

## ESP32 Not Connecting to WiFi
- Verify SSID and password in NVS
- Check WiFi signal strength
- Reboot ESP32: `esp_restart()`

## Device Showing Offline in UI
- Check last_seen timestamp (should be < 2 minutes)
- Verify network connectivity
- Check ESP32 logs for errors

## Authentication Failures
- Verify auth token matches database
- Check token not expired
- Re-provision device if needed

## Weather Data Not Updating
- Check aviation.weather.gov API status
- Verify WEATHER_STATION_ID configured
- Check server logs for API errors

## Fans Not Turning Off
- Expected behavior (fail-safe design)
- Verify wind speed below threshold
- Check for active time window overrides
```

### Known Limitations (AC8)
```markdown
# Known Limitations (POC)

1. **Single Weather Station** - All bunkers use same weather station
2. **No Multi-Tenancy** - Single organization only
3. **Basic Security** - No 2FA, password reset via manual DB update
4. **No Audit Logging** - User actions not logged
5. **Manual Scaling** - No auto-scaling infrastructure
6. **Limited Monitoring** - No Prometheus/Grafana integration
7. **No Mobile App** - Web UI only (responsive design)
8. **Basic Error Handling** - Some edge cases not handled
9. **No Backup/Restore** - Manual database backup required
10. **OTA Updates Optional** - Manual firmware flashing primary method
```
