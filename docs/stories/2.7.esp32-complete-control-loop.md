# Story 2.7: ESP32 Complete Control Loop Integration

## Status
Ready for Dev

## Story
**As an** ESP32 device,
**I want** a fully integrated control loop that coordinates WiFi, timer, relay, and server communication,
**so that** the system operates as designed with proper fail-safe behavior.

## Acceptance Criteria

1. Main app_main() initializes all components in correct order
2. Control loop coordinates: status reporting, server response handling, timer updates, relay control
3. Server shutdown_allowed=true triggers timer reset and relay_set_off()
4. Server shutdown_allowed=false triggers relay_set_on() immediately
5. Timer expiration triggers relay_force_on()
6. WiFi disconnect triggers relay_force_on() after dead-man expires
7. All state transitions logged clearly
8. System recovers automatically after transient failures
9. Continuous operation for 24+ hours verified in bench test
10. All components work together without race conditions

## Tasks / Subtasks

- [ ] Create main control loop

## Dev Notes

```c
void app_main(void) {
    // Initialize in order
    relay_controller_init();      // FIRST: Ensure fail-safe state
    watchdog_init();
    wifi_init();
    initialize_sntp();
    deadman_timer_init();

    // Start tasks
    xTaskCreate(control_loop_task, "control_loop", 4096, NULL, 5, NULL);
    xTaskCreate(status_reporting_task, "status_report", 4096, NULL, 4, NULL);
}

void control_loop_task(void *pvParameters) {
    while (1) {
        if (wifi_is_connected()) {
            // Send status, get decision
            server_decision_t decision = send_status_to_server();

            if (decision.reset_countdown) {
                deadman_timer_reset();
            }

            if (decision.shutdown_allowed) {
                relay_set_off();  // Save energy
            } else {
                relay_set_on();   // Safety
            }
        }

        esp_task_wdt_reset();
        vTaskDelay(pdMS_TO_TICKS(1000));
    }
}
```
