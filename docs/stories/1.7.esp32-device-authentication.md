# Story 1.7: ESP32 Device Authentication Flow

## Status
Done

## Story
**As an** ESP32 device,
**I want** to authenticate with the server using my provisioned token,
**so that** the server validates my identity and accepts my API requests.

## Acceptance Criteria

1. ESP32 loads device auth token from NVS on boot
2. Auth token included in Authorization header for all API requests (FR16)
3. Server validates token and returns 200 OK for valid requests
4. Server returns 401 Unauthorized for invalid/missing tokens
5. ESP32 handles 401 responses and enters fail-safe mode (fans ON)
6. ESP32 logs authentication status (success/failure) via ESP_LOG
7. Token validation failure triggers relay to turn fans ON
8. No retry on 401 errors (permanent failure until reprovisioned)
9. First connection attempt after boot verifies authentication
10. Authentication failure clearly logged with server response code

## Dev Notes

### Authentication Flow Sequence

1. ESP32 boots and initializes NVS
2. Load auth_token from NVS (or detect unprovisioned)
3. Connect to WiFi
4. Perform first HTTP POST to /api/v1/control/status with auth token
5. Server validates token against database
6. Server returns 200 OK or 401 Unauthorized
7. ESP32 handles response:
   - 200: Continue normal operation
   - 401: Enter fail-safe mode, fans ON, log error

### Authentication Code Pattern

```c
#define AUTH_TOKEN_MAX_LEN 37  // UUID string length

static char device_auth_token[AUTH_TOKEN_MAX_LEN] = {0};
static bool is_authenticated = false;

esp_err_t load_device_auth_token(void) {
    esp_err_t err = nvs_load_auth_token(device_auth_token);
    if (err != ESP_OK) {
        ESP_LOGW(TAG, "No auth token found in NVS - device not provisioned");
        return err;
    }

    ESP_LOGI(TAG, "Auth token loaded from NVS (first 8 chars): %.8s...", device_auth_token);
    return ESP_OK;
}

esp_err_t http_post_status_with_auth(void) {
    if (strlen(device_auth_token) == 0) {
        ESP_LOGE(TAG, "Cannot send status - no auth token");
        relay_force_on();
        return ESP_FAIL;
    }

    // Set authorization header
    char auth_header[256];
    snprintf(auth_header, sizeof(auth_header), "Bearer %s", device_auth_token);
    esp_http_client_set_header(client, "Authorization", auth_header);

    // Perform POST request
    esp_err_t err = esp_http_client_perform(client);
    if (err != ESP_OK) {
        ESP_LOGE(TAG, "HTTP POST failed: %s", esp_err_to_name(err));
        relay_force_on();
        return err;
    }

    // Check authentication
    int status_code = esp_http_client_get_status_code(client);

    if (status_code == 200) {
        ESP_LOGI(TAG, "Authentication successful");
        is_authenticated = true;
        return ESP_OK;
    } else if (status_code == 401) {
        ESP_LOGE(TAG, "Authentication failed - invalid or expired token (401)");
        is_authenticated = false;
        relay_force_on();
        return ESP_FAIL;
    } else {
        ESP_LOGW(TAG, "Unexpected HTTP status: %d", status_code);
        return ESP_FAIL;
    }
}
```

### First Boot Authentication Check

```c
void verify_device_authentication(void) {
    ESP_LOGI(TAG, "Verifying device authentication with server...");

    esp_err_t err = http_post_status_with_auth();

    if (err == ESP_OK && is_authenticated) {
        ESP_LOGI(TAG, "✓ Device successfully authenticated with server");
        ESP_LOGI(TAG, "✓ Proceeding to normal operation");
    } else {
        ESP_LOGE(TAG, "✗ Device authentication FAILED");
        ESP_LOGE(TAG, "✗ Entering fail-safe mode - fans will remain ON");
        ESP_LOGE(TAG, "✗ Device may need reprovisioning");
        // relay_force_on() already called in http_post_status_with_auth
    }
}
```

### Server-Side Token Validation (Reference)

Server validates token from Authorization header:
```python
# Backend validation (for reference)
async def validate_device_token(token: str, session: AsyncSession) -> Device:
    device = await session.execute(
        select(Device).where(Device.auth_token == UUID(token))
    )
    device = device.scalar_one_or_none()

    if device is None:
        raise HTTPException(status_code=401, detail="Invalid device token")

    # Update last_seen timestamp
    device.last_seen = datetime.utcnow()
    await session.commit()

    return device
```
