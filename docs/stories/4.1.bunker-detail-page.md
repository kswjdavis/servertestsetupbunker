# Story 4.1: Bunker Detail Page with Fan Diagram

## Status
Ready for Dev

## Story
**As a** web UI operator,
**I want** detailed bunker page showing visual fan layout with real-time status,
**so that** I can see which specific fans are running or stopped (FR28, FR29).

## Acceptance Criteria

1. Bunker detail page accessible via /bunkers/:id route
2. Page shows bunker name, location, and configuration
3. Visual fan diagram displays fans in grid layout based on fan_count
4. Each fan shows: Position number, Online/Offline status, Relay state (ON/OFF)
5. Fan icons colored: Green (ON/online), Blue (OFF/online), Red (offline)
6. Click fan navigates to device details
7. Poll GET /api/v1/bunkers/:id/status every 2 seconds
8. Loading state while fetching bunker data
9. 404 page if bunker not found
10. Responsive layout works on tablet and desktop

### Component Implementation Pattern

[Source: architecture.md#Frontend Architecture - Component Template Example]

```typescript
// pages/BunkerDetailPage.tsx
import React, { useState, useEffect } from 'react';
import { useParams, useNavigate } from 'react-router-dom';
import { usePoll } from '@/hooks/usePoll';
import * as bunkerService from '@/services/bunker.service';
import { FanGrid } from '@/components/bunker/FanGrid';
import { BunkerInfo } from '@/components/bunker/BunkerInfo';

export const BunkerDetailPage: React.FC = () => {
  const { id } = useParams<{ id: string }>();
  const navigate = useNavigate();
  const [bunkerData, setBunkerData] = useState(null);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  // Poll bunker status every 2 seconds
  const { data, error: pollError } = usePoll(
    () => bunkerService.getBunkerStatus(id),
    2000  // 2 second interval
  );

  useEffect(() => {
    if (data) {
      setBunkerData(data);
      setLoading(false);
    }
    if (pollError?.status === 404) {
      navigate('/404');
    }
  }, [data, pollError]);

  if (loading) return <LoadingSkeleton />;
  if (error) return <ErrorDisplay error={error} />;

  return (
    <div className="container mx-auto p-6">
      <BunkerInfo bunker={bunkerData.bunker} />
      <FanGrid
        devices={bunkerData.devices}
        onFanClick={(deviceId) => navigate(`/devices/${deviceId}`)}
      />
    </div>
  );
};
```

### Polling Implementation

Use custom usePoll hook for real-time updates:
[Source: architecture.md#Tech Stack - State Management]

```typescript
// hooks/usePoll.ts (if not already created in story 3.8)
import { useState, useEffect, useRef } from 'react';

export function usePoll<T>(
  fetchFn: () => Promise<T>,
  interval: number
) {
  const [data, setData] = useState<T | null>(null);
  const [error, setError] = useState<any>(null);
  const intervalRef = useRef<NodeJS.Timeout>();

  useEffect(() => {
    const poll = async () => {
      try {
        const result = await fetchFn();
        setData(result);
        setError(null);
      } catch (err) {
        setError(err);
      }
    };

    poll(); // Initial fetch
    intervalRef.current = setInterval(poll, interval);

    return () => {
      if (intervalRef.current) {
        clearInterval(intervalRef.current);
      }
    };
  }, [fetchFn, interval]);

  return { data, error };
}
```

### Fan Status Color Coding

[Source: architecture.md#Frontend Architecture - Component Template Example]

```typescript
// components/bunker/FanStatusCard.tsx
const getStatusColor = (fan: FanStatus) => {
  if (!fan.is_online) return 'bg-red-500';  // Offline = Red
  if (fan.relay_state === 'ON') return 'bg-green-500';  // ON/Online = Green
  return 'bg-blue-500';  // OFF/Online = Blue
};

const getStatusText = (fan: FanStatus) => {
  if (!fan.is_online) return 'Offline';
  return fan.relay_state === 'ON' ? 'Running' : 'Off (Energy Saving)';
};
```
