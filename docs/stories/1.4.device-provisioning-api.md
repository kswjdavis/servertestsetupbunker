# Story 1.4: Device Provisioning API

## Status
Ready for Dev

## Story
**As a** system administrator,
**I want** API endpoints to provision new ESP32 devices and generate authentication tokens,
**so that** devices can be registered in the system and assigned to bunkers.

## Acceptance Criteria

1. POST /api/v1/devices/provision endpoint creates device with unique auth token
2. Auth token is UUID4 format and stored securely in database
3. Device is assigned unique LED flash sequence (1-10, auto-incremented per bunker)
4. Endpoint validates bunker_id exists before creating device
5. Endpoint enforces unique constraint on mac_address
6. Endpoint enforces unique (bunker_id, fan_position) combination
7. Response includes device_id, auth_token (shown only once), and led_flash_sequence
8. GET /api/v1/devices endpoint lists all provisioned devices
9. GET /api/v1/devices/{device_id} endpoint returns device details (without auth_token)
10. DELETE /api/v1/devices/{device_id} endpoint deprovisions device
11. All endpoints require valid user authentication
12. Unit tests cover provisioning logic and validations

## Dev Notes

### Device Provisioning Logic

From requirements (FR6, FR9, FR10):
- FR6: Server shall maintain registry of all provisioned ESP32 controllers with unique identifiers, authentication tokens, and bunker/fan position assignments
- FR9: Server shall generate unique UUID-based authentication tokens during device provisioning
- FR10: Server shall validate device authentication tokens on every API request

```python
import uuid
from sqlalchemy import select, func
from app.models.device import Device
from app.models.bunker import Bunker

async def provision_device(
    session: AsyncSession,
    bunker_id: UUID,
    fan_position: int,
    mac_address: str
) -> Device:
    # Validate bunker exists
    bunker = await session.get(Bunker, bunker_id)
    if not bunker:
        raise HTTPException(status_code=404, detail="Bunker not found")

    # Check if fan_position already taken
    existing = await session.execute(
        select(Device).where(
            Device.bunker_id == bunker_id,
            Device.fan_position == fan_position
        )
    )
    if existing.scalar_one_or_none():
        raise HTTPException(status_code=409, detail="Fan position already assigned")

    # Generate LED flash sequence (auto-increment)
    count_result = await session.execute(
        select(func.count(Device.id)).where(Device.bunker_id == bunker_id)
    )
    device_count = count_result.scalar()
    led_flash_sequence = device_count + 1

    if led_flash_sequence > 10:
        raise HTTPException(status_code=400, detail="Maximum 10 devices per bunker")

    # Create device with auto-generated UUID auth token
    device = Device(
        id=uuid.uuid4(),
        auth_token=uuid.uuid4(),  # Auto-generated UUID token
        bunker_id=bunker_id,
        fan_position=fan_position,
        mac_address=mac_address,
        led_flash_sequence=led_flash_sequence,
        firmware_version="unknown"  # Will be updated when device first connects
    )

    session.add(device)
    await session.commit()
    await session.refresh(device)

    return device
```

### API Endpoint Example

```python
from fastapi import APIRouter, Depends, HTTPException
from app.schemas.device import DeviceProvisionRequest, DeviceProvisionResponse, DeviceResponse
from app.repositories.device_repository import DeviceRepository
from app.core.security import get_current_user

router = APIRouter(prefix="/api/v1/devices", tags=["devices"])

@router.post("/provision", response_model=DeviceProvisionResponse, status_code=201)
async def provision_device(
    request: DeviceProvisionRequest,
    session: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    """
    Provision a new ESP32 device and generate authentication token.

    **WARNING:** The auth_token is returned only once. Store it securely.
    """
    device_repo = DeviceRepository(session)
    device = await device_repo.provision_device(
        bunker_id=request.bunker_id,
        fan_position=request.fan_position,
        mac_address=request.mac_address
    )

    return DeviceProvisionResponse(
        device_id=device.id,
        auth_token=device.auth_token,  # Only returned on provisioning!
        led_flash_sequence=device.led_flash_sequence,
        message="Device provisioned successfully. Store auth_token securely - it won't be shown again."
    )

@router.get("", response_model=List[DeviceResponse])
async def list_devices(
    session: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    device_repo = DeviceRepository(session)
    devices = await device_repo.list_devices()
    return devices

@router.get("/{device_id}", response_model=DeviceResponse)
async def get_device(
    device_id: UUID,
    session: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    device_repo = DeviceRepository(session)
    device = await device_repo.get_device(device_id)
    if not device:
        raise HTTPException(status_code=404, detail="Device not found")
    return device

@router.delete("/{device_id}", status_code=204)
async def deprovision_device(
    device_id: UUID,
    session: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    device_repo = DeviceRepository(session)
    await device_repo.delete_device(device_id)
```

### Pydantic Schemas

```python
from pydantic import BaseModel, Field
from uuid import UUID
from datetime import datetime

class DeviceProvisionRequest(BaseModel):
    bunker_id: UUID
    fan_position: int = Field(ge=1, description="Fan position in bunker (1-based)")
    mac_address: str = Field(pattern=r"^([0-9A-Fa-f]{2}:){5}[0-9A-Fa-f]{2}$")

class DeviceProvisionResponse(BaseModel):
    device_id: UUID
    auth_token: UUID  # Only shown once!
    led_flash_sequence: int
    message: str

class DeviceResponse(BaseModel):
    id: UUID
    bunker_id: UUID
    fan_position: int
    mac_address: str
    firmware_version: str | None
    last_seen: datetime | None
    provisioned_at: datetime
    led_flash_sequence: int
    is_online: bool  # Computed: last_seen within 2 minutes

    class Config:
        from_attributes = True
```

### Security Note

The auth_token is sensitive and should:
1. Be returned only once during provisioning
2. Never be logged in plain text
3. Be excluded from GET endpoints
4. Be transmitted only over HTTPS
