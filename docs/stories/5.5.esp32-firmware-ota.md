## Story
**As a** system administrator,
**I want** ability to update ESP32 firmware over-the-air,
**so that** I can deploy firmware updates without physical access to devices.

## Acceptance Criteria

1. ESP32 supports OTA updates via HTTPS
2. Firmware binary hosted on server at /api/v1/firmware/latest.bin
3. ESP32 checks for updates every 24 hours
4. Update process preserves NVS data (WiFi credentials, auth token)
5. Failed update rolls back to previous firmware
6. OTA progress logged via ESP_LOG
7. Device reports firmware version in status reports
8. Backend API endpoint to upload new firmware binary
9. UI shows firmware version for each device
10. Documented rollback procedure if OTA fails

**ota_updater.c (using ESP-IDF OTA APIs):**
```c
// firmware/main/ota_updater.c
#include "esp_ota_ops.h"
#include "esp_https_ota.h"
#include "esp_log.h"

static const char *TAG = "OTA";

// AC1, AC3: HTTPS OTA update
esp_err_t perform_ota_update(const char *firmware_url) {
    esp_http_client_config_t config = {
        .url = firmware_url,  // AC2: Server URL
        .cert_pem = server_cert_pem_start,  // AC1: HTTPS
        .timeout_ms = 30000,
    };

    esp_https_ota_config_t ota_config = {
        .http_config = &config,
    };

    ESP_LOGI(TAG, "Starting OTA update from %s", firmware_url);

    // AC5: Automatic rollback on failure
    esp_err_t ret = esp_https_ota(&ota_config);

    if (ret == ESP_OK) {
        ESP_LOGI(TAG, "OTA update successful. Rebooting...");
        esp_restart();
    } else {
        ESP_LOGE(TAG, "OTA update failed: %s", esp_err_to_name(ret));
        // AC5: Previous firmware still active
        return ret;
    }

    return ESP_OK;
}

// AC3: Check for updates every 24 hours
void ota_check_task(void *pvParameters) {
    while (1) {
        vTaskDelay(pdMS_TO_TICKS(24 * 60 * 60 * 1000));  // 24 hours

        // Query server for new firmware version
        char firmware_url[256];
        if (check_new_firmware_available(firmware_url, sizeof(firmware_url))) {
            ESP_LOGI(TAG, "New firmware available!");
            perform_ota_update(firmware_url);
        }
    }
}
```

**NVS Preservation (AC4):**
NVS data automatically preserved across OTA updates when using standard ESP-IDF partition scheme. Ensure `partitions.csv` has separate NVS partition:

```csv
# Name,   Type, SubType, Offset,  Size
nvs,      data, nvs,     0x9000,  0x6000
phy_init, data, phy,     0xf000,  0x1000
factory,  app,  factory, 0x10000, 1M
ota_0,    app,  ota_0,   ,        1M
ota_1,    app,  ota_1,   ,        1M
```

### Backend Firmware Management (AC2, AC8)

**firmware.py (NEW):**
```python
# server/app/api/firmware.py
from fastapi import APIRouter, File, UploadFile, Depends
from pathlib import Path

router = APIRouter(prefix="/firmware", tags=["firmware"])

FIRMWARE_STORAGE = Path("/home/bunkercolab/firmware_storage")

@router.post("/upload")
async def upload_firmware(
    file: UploadFile = File(...),
    current_user: User = Depends(get_current_admin_user)  # Admin only
):
    """AC8: Upload new firmware binary"""
    firmware_path = FIRMWARE_STORAGE / "latest.bin"

    with open(firmware_path, "wb") as f:
        content = await file.read()
        f.write(content)

    return {"status": "uploaded", "filename": "latest.bin"}

@router.get("/latest.bin")
async def download_latest_firmware():
    """AC2: ESP32 downloads firmware from this endpoint"""
    firmware_path = FIRMWARE_STORAGE / "latest.bin"
    return FileResponse(firmware_path)
```

### OTA Update Procedure (AC10)

**docs/ota-update-procedure.md:**
```markdown
## ESP32 OTA Update Procedure

### Upload New Firmware
1. Build firmware: `cd firmware && idf.py build`
2. Upload via Web UI or API:
   ```bash
   curl -X POST -F "file=@build/firmware.bin" \
     -H "Authorization: Bearer $ADMIN_TOKEN" \
     https://server.com/api/v1/firmware/upload
   ```

### Trigger OTA Update
- Automatic: Devices check every 24 hours
- Manual: Trigger via API (future enhancement)

### Rollback on Failure (AC5, AC10)
ESP-IDF OTA automatically rolls back to previous firmware if:
- New firmware fails to boot
- CRC check fails during download
- Watchdog timeout occurs

### Verify Update Success
1. Check device firmware version in Web UI
2. Monitor ESP32 serial logs for "OTA update successful"
3. Verify device connectivity after reboot
```
