# Story 1.6: ESP32 HTTPS Client with TLS Validation

## Status
Draft

## Story
**As an** ESP32 firmware developer (Jeff),
**I want** HTTPS client that validates server TLS certificates,
**so that** ESP32 can communicate securely with the cloud server.

## Acceptance Criteria

1. ESP32 HTTPS client configured with esp_http_client
2. Server TLS certificate validated using root CA bundle (FR15)
3. HTTP Authorization header includes device auth token (FR16)
4. Client timeout set to 10 seconds
5. Retry logic: 3 attempts with exponential backoff on failure
6. HTTPS POST request to server status endpoint succeeds
7. Response JSON parsed using cJSON library
8. Connection errors logged with esp_err_t codes
9. SNTP time synchronization implemented for TLS validation
10. Code handles network timeouts gracefully

- [ ] Initialize SNTP for time sync (AC: 9)
  - [ ] Configure SNTP client (pool.ntp.org)

## Dev Notes

### HTTPS Client Configuration (ESP-IDF 5.x)

```c
#include "esp_http_client.h"
#include "esp_tls.h"
#include "cJSON.h"

extern const uint8_t root_cert_pem_start[] asm("_binary_root_cert_pem_start");

esp_http_client_config_t config = {
    .url = "https://yourdomain.com/api/v1/control/status",
    .method = HTTP_METHOD_POST,
    .cert_pem = (const char *)root_cert_pem_start,  // Root CA bundle
    .timeout_ms = 10000,
    .event_handler = http_event_handler,
};

esp_http_client_handle_t client = esp_http_client_init(&config);
```

### Authorization Header

### Retry with Exponential Backoff

```c
esp_err_t http_post_with_retry(const char *json_payload) {
    int retry_count = 0;
    const int max_retries = 3;
    esp_err_t err = ESP_FAIL;

    while (retry_count < max_retries) {
        esp_http_client_set_post_field(client, json_payload, strlen(json_payload));
        err = esp_http_client_perform(client);

        if (err == ESP_OK) {
            int status_code = esp_http_client_get_status_code(client);
            ESP_LOGI(TAG, "HTTP Status: %d", status_code);
            return ESP_OK;
        }

        retry_count++;
        int delay_ms = (1 << (retry_count - 1)) * 1000;  // 1s, 2s, 4s
        ESP_LOGW(TAG, "HTTP request failed, retry %d/%d in %dms", retry_count, max_retries, delay_ms);
        vTaskDelay(pdMS_TO_TICKS(delay_ms));
    }

    ESP_LOGE(TAG, "HTTP request failed after %d attempts", max_retries);
    return err;
}
```

### SNTP Time Synchronization

```c
#include "esp_sntp.h"

void initialize_sntp(void) {
    ESP_LOGI(TAG, "Initializing SNTP");
    esp_sntp_setoperatingmode(SNTP_OPMODE_POLL);
    esp_sntp_setservername(0, "pool.ntp.org");
    esp_sntp_init();

    // Wait for time sync
    time_t now = 0;
    struct tm timeinfo = { 0 };
    int retry = 0;
    const int retry_count = 10;

    while (timeinfo.tm_year < (2016 - 1900) && ++retry < retry_count) {
        ESP_LOGI(TAG, "Waiting for system time to be set... (%d/%d)", retry, retry_count);
        vTaskDelay(pdMS_TO_TICKS(2000));
        time(&now);
        localtime_r(&now, &timeinfo);
    }

    ESP_LOGI(TAG, "Time synchronized: %s", asctime(&timeinfo));
}
```

### JSON Response Parsing

```c
void parse_server_response(const char *response_buffer) {
    cJSON *json = cJSON_Parse(response_buffer);
    if (json == NULL) {
        ESP_LOGE(TAG, "Failed to parse JSON response");
        return;
    }

    cJSON *shutdown_allowed = cJSON_GetObjectItem(json, "shutdown_allowed");
    cJSON *reset_countdown = cJSON_GetObjectItem(json, "reset_countdown");

    if (cJSON_IsBool(shutdown_allowed)) {
        bool allowed = cJSON_IsTrue(shutdown_allowed);
        ESP_LOGI(TAG, "Shutdown allowed: %s", allowed ? "true" : "false");
    }

    cJSON_Delete(json);
}
```
