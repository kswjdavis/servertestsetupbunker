# Story 2.6: Bunker Management API (Backend)

## Status
Done

## Story
**As a** system administrator,
**I want** API endpoints to create, read, update, and delete bunker configurations,
**so that** I can manage bunker locations, orientations, and settings (FR7).

## Acceptance Criteria

1. POST /api/v1/bunkers - Create new bunker
2. GET /api/v1/bunkers - List all bunkers
3. GET /api/v1/bunkers/{id} - Get bunker details with device count
4. PUT /api/v1/bunkers/{id} - Update bunker configuration
5. DELETE /api/v1/bunkers/{id} - Delete bunker (and cascade delete devices)
6. All endpoints require authentication
7. Bunker validation: latitude (-90 to 90), longitude (-180 to 180), orientation (0-360)
8. Default values applied from GlobalConfig if not specified
9. Unit tests cover CRUD operations and validations
10. OpenAPI schema generated automatically

## Dev Notes

```python
from pydantic import BaseModel, Field, field_validator

class BunkerCreate(BaseModel):
    name: str = Field(min_length=1, max_length=100)
    latitude: float = Field(ge=-90, le=90)
    longitude: float = Field(ge=-180, le=180)
    orientation_degrees: float = Field(ge=0, lt=360)
    fan_count: int = Field(ge=1, le=10)
    wind_threshold_mph: float | None = None
    electricity_cost_kwh: float = Field(gt=0)
    fan_power_watts: int = Field(gt=0)

@router.post("", response_model=BunkerResponse, status_code=201)
async def create_bunker(
    bunker: BunkerCreate,
    session: AsyncSession = Depends(get_db),
    current_user: User = Depends(get_current_user)
):
    bunker_repo = BunkerRepository(session)
    new_bunker = await bunker_repo.create(**bunker.dict())
    return new_bunker
```
