## Troubleshooting Guide

### LED Not Flashing

**Possible Causes:**
1. WiFi not connected (LED starts only after WiFi - AC6)
   - **Fix:** Check WiFi credentials in NVS, verify network availability

2. Incorrect GPIO pin configured
   - **Fix:** Run `grep CONFIG_LED_GPIO_PIN build/config/sdkconfig.h` to verify

3. LED module wiring incorrect
   - **Fix:** Verify VCC, GND, and Signal (GPIO 5) connections

4. LED module polarity reversed (active-high vs active-low)
   - **Fix:** Check Keyes LED module datasheet for signal polarity

5. Device not provisioned (may default to sequence 1)
   - **Fix:** Check logs for "Device provisioned" message

### LED Timing Incorrect

**Possible Causes:**
1. FreeRTOS tick rate misconfigured
   - **Fix:** Check `CONFIG_FREERTOS_HZ` in sdkconfig (should be 100 or 1000)

2. Task priority too low (starved by other tasks)
   - **Fix:** Check LED task priority in logs (should be 3)

3. System under heavy load
   - **Fix:** Disable other tasks temporarily for isolated testing

### Task Crashes or Stops

**Possible Causes:**
1. Stack overflow
   - **Fix:** Check logs for "Task watchdog" or increase stack size

2. Memory corruption
   - **Fix:** Run with heap debugging enabled

3. GPIO conflict with other peripherals
   - **Fix:** Verify GPIO 5 not used by SPI, I2C, or other drivers
